# BookConv 部署服务器选型指南

## 运行环境要求

| 依赖 | 最低配置 | 说明 |
|------|---------|------|
| CPU | 1 Core | Node.js 单进程 |
| 内存 | 512MB+ | 含 Redis + Node 进程 |
| 磁盘 | 5GB+ | 系统 + Node 模块 + 临时文件 |
| OS | Ubuntu 22.04 LTS | 推荐 |

核心需求：**Redis + Calibre**。只要这两样装好，应用即可运行。

---

## 方案对比

### ⭐ 方案 A：Vercel（强烈推荐）

- **地址**: vercel.com
- **价格**: 免费 (Hobby 版)
- **类型**: Serverless 平台

**优点：** 零运维、全球 CDN、国内访问快、HTTPS 自动配置、Next.js 亲儿子框架
**缺点：** 不支持后台常驻 Worker、函数冷启动 2-3 秒
**适合：** 起步阶段、个人项目

### 方案 B：Hetzner Cloud

- **套餐**: CX22 = €4.51/月
- **配置**: 2 vCPU / 2GB RAM / 20GB SSD
- **机房**: 德国

**优点：** 性价比之王
**缺点：** 机房在欧洲，国内访问慢，需配 CDN

### 方案 C：阿里云 ECS

- **套餐:** 入门型 2C2G ~¥30-50/月
- **数据中心:** 香港/新加坡（免备案）

**优点：** 国内访问快、新用户优惠
**缺点：** 大陆节点需 ICP 备案

### 方案 D：DigitalOcean

- **套餐:** Droplet 2GB = $12/月
- **数据中心:** 有台湾节点

**优点：** 新手友好、文档极好、有台湾节点
**缺点：** 比 Hetzner 贵

### 方案 E：Railway

- **价格:** $5/月起
- **类型:** PaaS（含 Redis）

**优点：** 一键创建 Redis、自带 CI/CD
**缺点：** 免费试用后按量计费

---

## 推荐

**🏆 Vercel** — 最快上线，免费额度足够初期使用
**🥈 Hetzner** — 需要完整功能（后台 Worker）时的最佳选择
