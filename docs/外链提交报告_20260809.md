```
I Built a Free Ebook Converter That Actually Works (No Signup, No Ads)

Every time I needed to convert an ebook format, I hit the same wall:

- Convertio charges for anything over 50MB
- CloudConvert requires signup for full features
- Zamzar is buried under ads
- Most tools don't support niche formats like LIT or CBR

So I built FreeBookConvert — a free online ebook converter that just works.

### What it does

Convert 28+ ebook formats instantly:
- EPUB, PDF, MOBI, AZW3 (Kindle)
- LIT, CBR, DJVU, RTF
- TXT, HTML, and more

No signup. No file size limits. Zero ads.

### Why I built it

I'm a solo developer working on the side. I needed a reliable tool for converting my own ebooks between formats, and I kept hitting paywalls or signup walls on every free converter I found.

Instead of accepting the status quo, I built my own.

### Tech stack

- Next.js 16 — frontend and API routes
- Calibre engine — the industry-standard desktop ebook tool
- BullMQ + Redis — async job queue for handling conversions
- Docker — containerized deployment
- Vercel — deployed at bookconv.com

### What makes it different

| Feature | FreeBookConvert | Most competitors |
|---------|----------------|------------------|
| File size limit | None | 50-100MB |
| Signup required | No | Yes |
| Ads | None | Many |
| Format support | 28+ | 10-15 |
| Price | Free | $5-15/month |

### Open source

The code is on GitHub. If you want to contribute, report issues, or fork it — be my guest.

Live: bookconv.com
GitHub: github.com/doujianwen/ebook-converter

### What's next

- Mobile app (React Native)
- Batch conversion
- API access for developers
- More format support (UDF, FB2, etc.)

Would love your feedback, especially on any format edge cases I might be missing!
```
