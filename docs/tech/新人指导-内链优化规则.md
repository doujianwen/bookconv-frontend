# 新人指导 · 内链优化规则（bookconv.com · v1）

> 适用对象：所有需要**新建或编辑网站内容**（博客 / 指南 / 转换落地页正文）的协作者。
> 生效版本：v1（2026-08-08 由内链审计报告提炼）
> 目的：让每一篇内容从产出第一天起就符合 SEO 内链规范，避免事后批量返工。

---

## 0. 先看懂站点的"三套子系统"

bookconv.com 的内容由三套**同构子系统**组成，新人最常搞混的就是它们之间的互链关系：

| 子系统 | 路径 | 角色 | 举例 |
|---|---|---|---|
| 博客 Blog | `/blog/*` | 话题文章、教程、经验 | `epub-to-word`、`rss` |
| 指南 Guide | `/guide/*` | 格式枢纽、对比、深度解析 | `azw3-vs-mobi`、`kindle-formats` |
| 转换页 Convert | `/convert/*` | 落地转化页（带工具 CTA） | `mobi-to-epub`、`epub-to-zip` |

**核心三角关系**：`指南 ↔ 博客 ↔ 转换页` 应当互相引流。指南是"知识中枢"，博客是"话题入口"，转换页是"成交终点"。三者自然互链，权重才流得动。

> 写正文时插的内链，目标只可能是这三类 slug（或 `/blog`、`/guide`、`/convert` 三个索引页），其余路径（如 `/en/...`、`/tools/...`）都是错的。

## 1. 内链优化规则（v1 · 七维度 16 条）

### 1.1 结构与可达性
- **R1 全局导航**：每页必须有稳定全局入口（header 或 footer）覆盖三大枢纽 `/convert`、`/blog`、`/guide`。
- **R2 首页枢纽链接**：首页必须链到 `/blog` 与 `/guide` 索引页。
- **R3 可达深度**：任意重要页距首页 ≤ 3 次点击（含全局导航 + 上下文链接）。

### 1.2 相关性
- **R4 主题相关才链**：仅在同一格式簇或同一意图簇内互链；禁止把不相干页面强行互链（如 16 个 niche 转换页无相关博文，不应硬加）。
- **R5 双向互链（自然时）**：若 A 主题相关 B，B 应回链 A。尤其转换对（epub↔mobi）与「指南 ↔ 博客 ↔ 转换页」三角。

### 1.3 锚文本
- **R6 描述性锚文本**：锚文本须为目标页主关键词，禁 "click here / here / 更多 / 阅读" 等通用词。
- **R7 锚文本匹配意图**：转换页锚用 "Convert X to Y"；指南锚用格式名；博客锚用文章标题/主题。

### 1.4 权重流向
- **R8 权重流向高价值页**：核心变现页（`mobi-to-epub` / `epub-to-mobi` / `azw3-to-mobi` / `pdf-to-epub`，即 GSC 高展示词）应获最多内链，经首页 `TOP_CONVERTERS` + 博客 CTA + 相关部件集中。
- **R9 枢纽页承接权重**：`/guide` 下的格式枢纽指南（如 `kindle-formats`、`azw3-vs-mobi`）应被博客与转换页回链，成为簇中枢。

### 1.5 孤儿页
- **R10 零孤儿（索引/导航除外）**：每篇已发布页须 ≥1 条来自其他已索引页的上下文入链。
- **R11 dev/infra 帖豁免**：纯技术帖（`rss`、`sitemap-seo-guide`、`webhook`、`env` 等）允许低入链，不计入孤儿缺陷。

### 1.6 断链与技术规范
- **R12 零断链**：所有内链必须解析为 200，禁链到已删/改名 slug、禁 `-en` 旧副本、禁指向未上线转换对（`epub-to-docx` / `mobi-to-azw3` 这类 404）。
- **R13 链规范 URL**：直链 canonical，不链会产生 301 跳转的 URL，不链软 404 薄页。
- **R14 多语种一致**：`/es` 镜像 `/en` 链接结构；锚文本与 href 不硬编码 `/en`；hreflang 互指。

### 1.7 数量与质量
- **R15 避免链接稀释**：禁止「链向全部其他页」式无差别堆链（当前指南 "More guides" 链 20 个其他指南即属此类）。相关部件应取 Top 3–5 真实相关项。
- **R16 上下文 > 样板**：正文内的自然相关链接权重大于页脚；优先在正文插入，而非只靠部件。

## 2. 新人上手三件事

### 2.1 写新内容前
1. 确认它在三套子系统中属于哪一类（Blog / Guide / Convert）。
2. 找到 1–3 个**同格式/同意图**的已有页面，准备在正文里自然互链。
3. 若是 Guide 类，想想它该承接哪些博客/转换页的权重回流（R9）。

### 2.2 写正文时（内链怎么插）
- 用真实 slug 写链接，例如：`[Convert EPUB to ZIP](/convert/epub-to-zip)`（**注意 CTA 用带 `to` 的路径**）。
- 锚文本写目标页主关键词，不要写"点击这里""更多"。
- 优先在**正文段落**里自然出现，而不是全堆在文末。
- 西语内容镜像英文结构，链接同样走 `/es/...`，**绝不能硬编码 `/en`**。

### 2.3 发布前自检清单（必过）
- [ ] 所有内链目标是真实存在的 slug（博客/指南/转换页），无拼写错误。
- [ ] **没有链向未上线的转换对**（常见坑：`epub-to-docx` 应为 `epub-to-word`；`mobi-to-azw3` 未上线）。
- [ ] 锚文本是描述性的，没有 "click here / 更多 / 阅读" 等通用词。
- [ ] 同一主题页做了**双向回链**（A 链 B，B 也链 A）。
- [ ] 没有"链全部其他同类页"的堆链行为（取 Top 3–5 相关即可）。
- [ ] 纯 niche 页不强加相关链接（R4 允许例外）；dev/infra 帖允许低入链（R11）。

## 3. 最容易踩的坑（血泪清单）

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 把 `epub-to-word` 写成 `/convert/epub-to-docx` | 404 断链（R12） | docx 即 word，用 `/convert/epub-to-word` |
| 链向 `mobi-to-azw3` | 该转换对未上线，404 | 改用 `/convert/mobi-to-epub` 或 `/convert/azw3-to-mobi` |
| 锚文本写"点击这里""更多" | 浪费锚文本权重（R6） | 写目标页主关键词 |
| 指南只链其他指南、不回链博客/转换 | 指南被排除在权重流外 | 指南正文回链相关博客，并接"Related blog"部件 |
| 硬性给无关 niche 页加链接 | 稀释相关性（R4） | 只链同簇；不相关的不强加 |
| 西语内容硬编码 `/en` 链接 | 多语种不一致、hreflang 错（R14） | 西语内容用 `/es/...` 镜像结构 |

## 4. 求助与复核

- 不确定某个转换对是否已上线：查 `src/lib/conversion-map.ts`（`CONVERSION_MAP` 是唯一真源，里面没有就是未上线）。
- 不确定某 slug 是否属于博客/指南：分别看 `src/data/blog/`、`src/data/guides/`、`src/data/content/` 目录。
- 发布后可复用审计脚本 `scripts/_audit_internal_links.mjs` 复跑，自动抓断链与零入链页。
- 完整审计依据见根目录 `内部链接审计报告-2026-08-08.md`。
