# 3. 内容生成

**一句话职责**：按意图和 SEO 规范生产高质量、可排名的英文内容。

**核心工作**：
- 博客：格式科普、对比、 troubleshooting、设备使用指南。
- 指南：深度教程、场景化选型、Calibre/CloudConvert 使用说明。
- 转换页：hero + sections + FAQ，英文无反引号，内链走真实 slug。
- 内容更新：根据 GSC/SERP 审计结果优化现有页面。

**典型交付物**：
- `src/data/blog/*.ts`、`src/data/guides/*.ts`、`src/data/content/*.ts` 数据文件；内容发布检查清单。

**不做什么**：
- 不做关键词研究（由 1.用户意图洞察 输入）。
- 不调整 URL/路由/canonical（由 2.SEO&GEO 定规范）。
- 不处理后端转换能力问题（由 6.产品技术 & 变现 确认）。

**协作规则**：
- 新建内容前确认目标页已被 6.产品技术 & 变现 确认可转换（避免软 404）。
- 发布后由 2.SEO&GEO 做技术/结构化数据检查，由 4.数据分析 追踪排名。

## 跨模块通用纪律（适用于所有模块）

1. **入口唯一**：同一个需求不要同时在两个任务里聊；先在对应模块里闭环，再跨模块同步。
2. **数据不回传则不算完成**：内容上线 → 4 追踪；外链发出 → 4 追踪；代码上线 → 7 验证 → 4 追踪。
3. **破坏性操作必须先清单再确认**：删除文件、大规模改 URL、改支付逻辑，必须列影响范围并得用户确认。
4. **远程同步规则**：
   - 有价值文档必须 commit + push。
   - 临时素材（竞品截图、一次性脚本、本地 txt）原则上不进 git，定期由 7 清理。
   - push 后必须等 Vercel 部署并做真渲染验证。
5. **自我进化**：任何跨模块踩坑，触发纠错智能体，把教训沉淀为 MEMORY.md 硬规则。
