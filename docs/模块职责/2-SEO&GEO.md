# 2. SEO & GEO

**一句话职责**：让搜索引擎和 AI 引擎能抓取、理解、信任并引用我们的页面。

**核心工作**：
- 技术 SEO：索引健康、渲染 bug、软 404、canonical/hreflang、sitemap、死链、Core Web Vitals。
- 内容 SEO：标题/H 结构、内链架构、schema（FAQPage / HowTo / SoftwareApplication / Article）、精选摘要优化。
- GEO：llms.txt、robots 放行 AI 爬虫、FAQ 结构化、E-E-A-T 信号、实体/作者信息。
- SERP 竞品方法论：定义分析维度、评分框架、复测节奏。

**典型交付物**：
- 技术 SEO 审计报告、SERP 竞品分析方法论、内链规则文档、schema 规范、GEO 优化清单。

**不做什么**：
- 不直接生产长内容正文（交给 3.内容生成）。
- 不处理支付/账号等技术功能（交给 6.产品技术 & 变现）。

**协作规则**：
- 所有新建/修改的页面在发布前必须过 seo-critic 门禁（死链、ES 键对齐、llms.txt 同步等）。
- 新页上线后 2–4 周由 4.数据分析 做 GSC 复测，再反馈给 2.SEO&GEO 调优。

## 跨模块通用纪律（适用于所有模块）

1. **入口唯一**：同一个需求不要同时在两个任务里聊；先在对应模块里闭环，再跨模块同步。
2. **数据不回传则不算完成**：内容上线 → 4 追踪；外链发出 → 4 追踪；代码上线 → 7 验证 → 4 追踪。
3. **破坏性操作必须先清单再确认**：删除文件、大规模改 URL、改支付逻辑，必须列影响范围并得用户确认。
4. **远程同步规则**：
   - 有价值文档必须 commit + push。
   - 临时素材（竞品截图、一次性脚本、本地 txt）原则上不进 git，定期由 7 清理。
   - push 后必须等 Vercel 部署并做真渲染验证。
5. **自我进化**：任何跨模块踩坑，触发纠错智能体，把教训沉淀为 MEMORY.md 硬规则。
