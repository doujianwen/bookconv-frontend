# 每周运营 Checklist

## 周一: 数据分析
- [ ] 查看上周转化漏斗数据 (Plausible/GA)，关注异常波动
- [ ] 检查各关键词排名变化 (用 Ahrefs/SerpAPI)
- [ ] 查看服务器健康状态 (CPU/内存/磁盘/R2 用量)

## 周二: Reddit/社区互动
- [ ] 在 r/Calibre 回答 3-5 个相关问题
- [ ] 在 r/kindle 回答 2-3 个相关问题
- [ ] 在 r/selfpublish 回答 2-3 个相关问题
- [ ] 在 r/ebooks 回答 2-3 个相关问题
- [ ] 检查是否有新评论/回复需要回应

## 周三: 内容创作
- [ ] 撰写/润色一篇博客或工具页内容
- [ ] 更新 S/A 级页面的内容深度
- [ ] 准备下周的 Medium/DEV.to 文章

## 周四: 外链拓展
- [ ] 联系 2-3 个电子书博客/网站
- [ ] 提交 1-2 个新工具目录
- [ ] 回复 Quora 问题 5-10 个
- [ ] 更新 GitHub 仓库

## 周五: 复盘规划
- [ ] 梳理本周用户反馈
- [ ] 规划下周优化项
- [ ] 检查转化率漏斗，找出瓶颈
- [ ] 更新外链追踪表格

---

## 每月复盘

### 第1周: 内容规划
- [ ] 确定本月重点内容主题
- [ ] 规划 S/A 级页面建设进度
- [ ] 确定外链拓展目标

### 第2-3周: 执行
- [ ] 按计划执行内容创作
- [ ] 执行外链拓展
- [ ] 监控 SERP 排名变化

### 第4周: 复盘
- [ ] 统计本月外链获取情况
- [ ] 分析各渠道 ROI
- [ ] 调整下月策略
- [ ] 更新收入预测
