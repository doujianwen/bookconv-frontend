# 竞品反链侦察清单（bookconv.com）

> 目的：通过 Ahrefs 免费反链检查器，找出竞品在哪些**目录站 / 资源页 / 工具列表页**被收录，
> 反推 bookconv.com 也能去提交的外链机会。
> 生成日期：2026-08-12
>
> ⚠️ 能力边界说明：本环境无 Ahrefs 账号/API，无法程序化抓取反链数据。
> 下方为每个竞品准备了**可点击的 Ahrefs 免费查询 URL**，在浏览器打开即可查看 top 100 反链（无需登录）。
> 所有 `DR` / `引用域数` / `机会` 列需你查完后手动回填。

---

## 一、怎么跑（3 步）

1. 点击下方任一竞品的 Ahrefs URL，在输入框确认域名，点 **Check backlinks**（免费、无需账号，看 top 100）。
2. 在结果里筛 **Directory / Resources / Tools / "submit" / .edu / 行业资源页** 类反链（这类 bookconv 也能去要）。
3. 把有价值的目标回填到下方「跟踪表」，再并入 `外链资源完整清单.md` 的提交队列（按 ROI 目录类优先）。

> 进阶：注册 **Bing Webmaster Tools**（免费、可查任意站点反链）交叉验证；
> **Moz Link Explorer** 每月 10 次免费看 DA/Spam Score 评估质量。

## 四、Google 补漏搜索式（Ahrefs 之外的辅助）

Ahrefs 免费只给 top 100，用下面 Google 提及搜索补漏（非反链列表，但能挖资源页）：

```
intext:"cloudconvert.com" "directory" -site:cloudconvert.com
intext:"convertio.com" "resources" -site:convertio.com
intitle:directory "ebook converter"
"submit your tool" "file converter"
```
