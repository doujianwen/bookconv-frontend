## 七-附、P0：Google 商业词失效诊断（2026-11-02 诊断完成 / 长期跟进）

> 来源：周报_关键词分析_2026-11-01.md（P0 提案：29 个「Bing≤10 且 Google≥50」商业词）+ docs/gsc-index-audit-2026-11-01/（117 URL 逐页诊断 01 + 结论红队审计 02 + 复查 06）。本 P0 诊断部分于 11-02 与既有索引审计交叉印证后完成；**修复为长期工程，不计入今日完成**。

### 诊断结论（✅ 2026-11-02 完成）

- **不是沙盒、不是惩罚。** 关键词报告里 29 个 Google 失效的商业词，其落地页在 GSC Inspection 中绝大多数是 **Discovered - currently not indexed（已发现、未编入索引）**。11-01 复查 30 个代表 URL：24 Discovered / 5 unknown / 1 已收录（`/es/guide/kindle-formats`，10-25 抓取）；全站 117 URL 同口径：82 已发现、28 unknown、4 已抓取未收录、2 已收录、1 接口错误。
- **根因 = 索引优先级低 + 域名权威度低（新/小站「已发现未索引」常态）**，不是算法打击。Bing 把这些页正常收录并排前 10；Google 仅「发现」未索引 → 商业词在 Google 零曝光零点击（GSC 总点击 14，且多为品牌词/已收录页）。
- **与既有红队交叉印证**：gsc-index-audit 02 文件 R02/R22 明确「28 unknown ≠ Google 惩罚/删除」，且「不放行：将这次检查表述为 Google 惩罚诊断」。本 P0 结论与此一致，**不采用惩罚叙事**。
- GSC 抓取统计（截至 10-30）：1107 次请求、97% 200、主机 90 天无异常、robots/DNS/连接失败率可接受 → **无技术阻断、无主机惩罚证据**。

### 14.6 ✅ R-2 实施：`PUT:NETWORK` 粗桶拆出 `PUT:CSP`（2026-11-06 11:00–11:30 CST · **本地完成，未部署**）

**动机**：10-27→11-06 的 P0 被连续读成「客户端网络抖动」约 10 天，根因就是诊断前缀只有一个 `NETWORK` 桶，
把「CSP 确定性拦截 / CORS 预检拒绝 / 真网络中断」混为一类。A1 修完 CSP 后必须补判别能力，否则同类缺陷会再次隐形。

**新增判别机制**（`src/lib/client/csp-violation.ts`）：
- 幂等挂 `document` 的 `securitypolicyviolation` 监听；有界缓冲（上限 16）。
- 三重归因才认定为 CSP：`at >= since` ∧ connect 型指令（`connect-src` / `default-src` 回退）∧
  `blockedURI` 的 host == 本次 upload host。他人违规、旧尝试残留、无 URI 一律不认（保守退回 NETWORK）。
- `detectCspBlock()` 内**必须** `await` 一个宏任务（见下）。

**实测事实（真实 Chromium，先测后写）**：
| 项 | 结果 |
|---|---|
| CSP 拦 fetch 是否触发事件 | 是；`effectiveDirective=connect-src`、`blockedURI`=presigned URL、`disposition=enforce` |
| 事件相对 reject 时序 | **晚约 1.7ms**（reject 16.1ms → event 17.8ms）⇒ 同步读取必落空 |
| 真网络中断是否误触发 | 否（0 事件） |
| 一个宏任务够否 | 够（8/8，中位额外 0.2ms） |

⇒ 若按直觉写同步读取，功能会「编译通过、测试绿、永久输出 NETWORK」完全空转。

**契约变更（必须同步 parser，否则 `malformed:true` 降级）**：
前缀 kind 由 `<HTTP<status>|NETWORK>` 扩为 `<HTTP<status>|CSP|NETWORK>`，向后兼容（历史前缀解析结果不变）。
`scripts/lib/direct-upload-diagnostic.mjs` 已同步 `PREFIX_RE` / `serializeDiagnostic` / `cspBlocked` 字段 /
枚举空间（240 组合）/ 两条私造 token 的漂移用例（`CSP-BLOCKED`、`CSPBLOCKED` 必须 malformed）。
另把 round-trip 断言修正为 `serialize(parse(x)) === x.prefix`（原断言假设 error 串恰等于纯前缀，带友好消息会误报）。

**附带修正**：`putToR2WithRetry` 在重试循环内判定 CSP，命中即中止重试 —— ① CSP 是确定性拒绝，重试 3 次纯浪费 ~1.2s；
