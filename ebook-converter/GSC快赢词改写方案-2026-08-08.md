## 四、内链纪律（仓库铁律）

1. **渲染器 `renderMarkdownToHtml` 不支持 `[text](url)`** —— sections 加 Markdown 链接不会转 `<a>`。
2. **内链走组件自动机制**：`RelatedConversions`（同格式相关转换）+ `relatedBlogPosts`（标签匹配）+ `Quick Answer` 的 `/pricing` 链接。
3. **CTA URL 格式铁律**：写 `/convert/{src}-to-{tgt}`（**带 to**），非 CONVERSION_MAP 键 `{src}-{tgt}`；漏 `to` → 500。
4. **正文必须全英文**，禁反引号，内链用真实 slug。

- 建议修复：`tableHtml += "<th...>" + h + "</th>"`；`<td>` 同理
- 本次未修（避免 scope creep + 需全站 regression 验证）
