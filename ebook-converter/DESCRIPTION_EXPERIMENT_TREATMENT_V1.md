## Page 1: `/convert/epub-to-doc`

### Current Description

```
Free EPUB to DOC converter. Extract text and formatting from EPUB files and save as Microsoft Word documents. No sign-up required. Works online instantly.
```

**Length**: 178 characters

### Diagnosis

| 问题 | 说明 |
|---|---|
| search intent 前置 ✅ | "Free EPUB to DOC converter" 开头 |
| capability 清晰 ✅ | "Extract text and formatting" 明确能力 |
| benefit 后置 ❌ | "No sign-up required" 和 "Works online instantly" 在末尾，信息密度低 |
| 冗余背景 ⚠️ | "Extract text and formatting" 与 title 重复 |
| 过长 ⚠️ | 178 字符超过推荐 160 |

### Proposed Description

```
Convert EPUB to DOC online — preserve formatting, no sign-up. Free tool for quick document conversion.
```

**Length**: 104 characters

### Hypothesis

> H-A1: 将核心 benefit（preserve formatting, no sign-up）前置可能提高 SERP snippet relevance 和 CTR。

## Page 2: `/convert/epub-to-zip`

### Current Description

```
Convert EPUB to ZIP free — one click pulls out the raw XHTML, images, and metadata from your EPUB. No account needed, instant download.
```

**Length**: 170 characters

### Diagnosis

| 问题 | 说明 |
|---|---|
| search intent 前置 ✅ | "Convert EPUB to ZIP free" 开头 |
| capability 清晰 ✅ | "pulls out the raw XHTML, images, and metadata" |
| benefit 后置 ⚠️ | "No account needed, instant download" 在末尾 |
| 过于技术 ❌ | "raw XHTML, images, and metadata" 对普通用户太技术 |
| 过长 ⚠️ | 170 字符超过推荐 160 |

### Proposed Description

```
Extract EPUB contents to ZIP — get XHTML, images, and metadata instantly. Free, no sign-up required.
```

**Length**: 98 characters

### Hypothesis

> H-A2: 更简洁的描述 + 突出「instantly」可能提高高排名页面的 CTR。

### Current Description

```
Free LIT to EPUB converter — rescue your old Microsoft Reader books. Convert LIT files to EPUB format quickly and easily. No software installation needed.
```

**Length**: 179 characters

### Diagnosis

| 问题 | 说明 |
|---|---|

```
Convert LIT to EPUB — rescue old Microsoft Reader books. Free online tool, no installation.
```

**Length**: 92 characters

### Hypothesis

> H-A3: 针对 niche 格式页面，强调「rescue old books」情感价值 + 无安装成本可能提高 CTR。

## 三、Treatment 原则总结

| 原则 | 说明 |
|---|---|
| 不机械截断 | 重写而非截断，保持语义完整 |
| 不堆 keyword | 不使用关键词堆砌 |
| 不虚构功能 | 只写页面实际支持的功能 |
| 卖点前置 | 核心 benefit 放前面 |
| 控制长度 | 目标 90-110 字符，留足显示空间 |
