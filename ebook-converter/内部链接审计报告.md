## 三、P1 · 落地页 → 博客 完全缺失（0/26）

26 个转换落地页**没有任何一个**链向博客文章。博客是高价值内容页，却收不到来自高权重落地页的链接权重（link equity），也没有"教程/指南"的转化钩子。

**关键判断（避免乱塞链接）**：只有当落地页的格式在博文里被真实讨论时，才应加 CTA。按格式相关性，真正值得加"相关指南"的约 **10 个核心转换页**：

| 落地页 | 应链向的博客（相关） |
|---|---|
| `/convert/epub-to-mobi` | how-to-convert-epub-to-mobi, epub-to-mobi-guide |
| `/convert/mobi-to-epub` | epub-to-mobi-guide, azw3-vs-mobi, ebook-formats-explained |
| `/convert/azw3-to-mobi` | azw3-vs-mobi, epub-to-mobi-guide |
| `/convert/azw3-to-epub` | azw3-vs-mobi, ebook-formats-explained |
| `/convert/epub-to-azw3` | azw3-vs-mobi, ebook-formats-explained |
| `/convert/epub-to-pdf` | epub-to-pdf-linux, pdf-to-epub-guide |
| `/convert/pdf-to-epub` | pdf-to-epub-guide, docx-to-epub |
| `/convert/lit-to-epub` | why-convert-lit-to-epub, lit-ebook-format |
| `/convert/epub-to-word` | epub-to-pdf-linux（含 Word 场景） |
| `/convert/docx-to-epub` | pdf-to-epub-guide |

**其余 16 个 niche 落地页（cbr/djvu/fb2/jpg/png/rtf/html/doc/txt 等）无相关博文**——强行加不相关链接是低质内链，不建议。这类"孤儿"的正确出路是后续补写对应博文，或靠转换页之间已有的相关转换互链 + 首页导航承接。

## 四、P2 · 博客间互链缺失（无"相关文章"基础设施）

目前除技术集群 5 篇（background-workers / webhook-integration / env-variables-setup / download-troubleshooting / epub-to-mobi-guide）互相引用外，其余博文**彼此零互链**。结果：

- 5 篇成为**孤儿博客**（无入链）：`epub-to-pdf-linux`、`sitemap-seo-guide`、`lit-ebook-format`、`azw3-vs-mobi`、`pdf-to-epub-guide`——恰好包含阶段2新发的 3 篇弱词博文，权重最难起来。

建议：在博客详情页底部加"Related posts"区块，按标签/格式相关性自动取 2–3 篇。这是可复用组件，一次实现、全站受益。
