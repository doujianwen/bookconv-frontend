# 转换后端接线指南（Vercel ↔ 装 Calibre 的 VPS）

> 背景：生产环境 26/27 个格式之前 100% 失败（BullMQ+Redis+常驻 worker 在 Vercel serverless 上不成立，且 Redis 不可达）。
> 已修复：`api/convert` 改为请求内**同步**执行，epub→zip 等纯透传已端到端验证通过（200 + 合法 ZIP）。
> 剩余缺口：Vercel 运行时**没有 Calibre 二进制**，25 个走 Calibre 的格式需在装了 Calibre 的 VPS 上跑。

## 我（AI）这次做了什么

调查了 VPS 现状，结论：**从我的环境无法触达 VPS**。
- `bookconv.com` → `216.198.79.1`（纯 Vercel IP），公网 DNS 全在 Vercel。
- 试过 `api/convert/backend/vps/worker.bookconv.com` 等子域 → 全部解析到本地路由器（NXDOMAIN 兜底），VPS 未挂在任何已知子域。
- VPS 主机地址只在 GitHub Actions Secrets（`secrets.PRODUCTION_HOST`）里，仓库文件里没有，我读不到，也没有 SSH 凭据。

因此「重部署 VPS + 设环境变量」这两步必须由你执行。我已把代码/配置侧全部准备好：

| 文件 | 改动 |
|------|------|
| `docker-compose.yml` | `app` 服务新增 `CONVERSION_INTERNAL_SECRET=${CONVERSION_INTERNAL_SECRET:-}`（VPS 重部署时从 `.env` 读入） |
| `.env.example` | 新增 `CONVERSION_BACKEND_URL` / `CONVERSION_INTERNAL_SECRET` 两个变量模板 + 架构说明 |
| `DEPLOYMENT.md` | 新增「Vercel 与 VPS 转换后端接线」整节（含命令） |
| （之前已提交）`api/convert/route.ts` | 设了 `CONVERSION_BACKEND_URL` 时转发到 VPS `/api/convert-internal` |
| （之前已提交）`api/convert-internal/route.ts` | VPS 侧执行端点，密钥保护（无密钥 → 403） |

## 你需要执行的 3 步

### ① 重部署 VPS（拉取含 convert-internal 的新代码）

```bash
ssh <你的 VPS>
cd /opt/ebook-converter
# 生成并写入内部密钥（与 Vercel 侧必须一致）
echo "CONVERSION_INTERNAL_SECRET=$(openssl rand -hex 32)" >> .env
docker compose pull app
docker compose up -d app
# 校验：无密钥应返回 403
curl -s -o /dev/null -w "%{http_code}\n" -X POST http://localhost:3000/api/convert-internal
# 期望输出: 403
```

> 自查 VPS 健康（Calibre + 本地 Redis）：`curl -s http://localhost:3000/api/health | jq`

### ② 在 Vercel 设 2 个环境变量

Vercel Dashboard → 项目 → Settings → Environment Variables：

| 变量 | 值 |
|------|-----|
| `CONVERSION_BACKEND_URL` | `https://<你的 VPS 域名或 IP>`（Vercel 出网可达 + HTTPS） |
| `CONVERSION_INTERNAL_SECRET` | 与 ① 中 VPS `.env` 里的随机串**完全一致** |

保存后 Vercel 自动重建。

### ③ 验证（在你本地或任意能上网的机器）

```bash
# 纯透传（Vercel 本地）：应直接返回合法 ZIP
curl -F "file=@sample.epub" -F "source_format=epub" -F "target_format=zip" \
  https://www.bookconv.com/api/convert -o out.zip
file out.zip   # Zip archive data

# Calibre 格式（经 VPS 委派）：应返回目标格式
curl -F "file=@sample.epub" -F "source_format=epub" -F "target_format=txt" \
  https://www.bookconv.com/api/convert -o out.txt
file out.txt  # Unicode text
```

## 安全提示

- `.env.production`（仓库根）里含真实 Lemon Squeezy 密钥——但 `.gitignore` 已忽略它，**未提交**，无泄露。VPS 实际运行配置来自 `/opt/ebook-converter/.env`（docker-compose 自动读取），请在那里管密钥。
- `CONVERSION_INTERNAL_SECRET` 是**防开放代理**的关键，务必用随机串、且 Vercel 与 VPS 两侧一致。

## 不接 VPS 会怎样

不设 `CONVERSION_BACKEND_URL`：epub→zip（及未来纯 JS/透传转换）正常可用，其余 25 个 Calibre 格式在 Vercel 上仍 500。设上后 27 个全通。
