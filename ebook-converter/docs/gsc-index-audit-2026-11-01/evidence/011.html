Public Datasets

Raw, downloadable measurement data from running an ebook converter site

Why we publish raw data

Most “SEO case study” content shows only conclusions. We publish the underlying measurements instead: normalized exports with source, collection window, sample size, and stated limitations, so any number we cite elsewhere can be checked against the data it came from.

Every dataset below is a record of one small website over a limited window. It is a case fact, not a general rule — please read each dataset's limitations section before reusing it.
