Error Code Reference

CONVERSION_FAILED

The conversion process failed. Try again or contact support with the error details.

FILE_TOO_LARGE

File exceeds the 4 MB limit. Free tier has a 60-second hard timeout — large files will fail. Try: ① Pure JS formats (EPUB→TXT/DOCX/RTF/FB2 have no size limit); ② Compress or split the file; ③ Use desktop Calibre for large files.

RATE_LIMIT

Too many requests. The limit is 20 conversions per minute. Wait a moment and try again.

DRM_PROTECTED

The source file is DRM-protected. We cannot convert protected files.

CORRUPT_INPUT

The uploaded file is corrupted or invalid. Please check the source file.

File Expiry Policy

For privacy protection, all converted files are automatically deleted after the conversion completes. This applies to all users, regardless of plan.

  • Always download immediately after conversion completes
  • Do not wait to batch-download multiple files
  • Files cannot be recovered after the expiry window

Quality Checklist

  • File size is reasonable (not 0 KB or unusually large)
  • Table of contents is present and clickable
  • Images display correctly
  • File opens in your target reader
  • Text flow and formatting look correct

If the quality isn't right, try converting from a different source format or adjusting the output settings.
