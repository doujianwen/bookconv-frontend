Frequently asked questions

What is batch ebook conversion?

Batch conversion lets you convert several ebook files to the same target format in one go. On BookConv you can upload several files per batch and download the results as a single ZIP.

Is batch conversion free?

Batch conversion is free during public beta, with no Pro subscription required. It is planned for Pro after beta; check this page for current availability.

Which formats can I convert in a batch?

The same formats as the single-file converter — EPUB, PDF, MOBI, AZW3, TXT, DOCX, RTF, FB2, DJVU and more. Every file in a batch is converted to the target format you pick.

How does BookConv batch conversion work?

BookConv converts each file through its conversion API and packages the results into a ZIP you download directly in your browser. There is no separate batch queue to wait on.

What is the maximum file size per file?

Each file in a batch can be up to 4 MB. EPUB to ZIP and EPUB to TXT accept up to 20 files; conversions using the third-party service currently accept up to 3 files. The single-file direct uploader has a separate limit.

What if one file in my batch fails?

If a single file fails (e.g., it's too large or corrupted), that file is skipped and the rest of your batch still converts successfully. You'll see which files succeeded and which failed in the result ZIP.

Why did my batch upload timeout?

Uploads may time out if you have many large files or a slow connection. Try uploading fewer files at once, or compress your EPUBs before batching. Batch limits apply during beta regardless of subscription.

Can I mix different source formats in one batch?

Yes — you can upload a mix of EPUB, MOBI, AZW3, PDF, etc. and they'll all be converted to the single target format you select.

Where do I find my batch results?

After all files finish converting, a download button appears for the result ZIP. Save it immediately — download links are temporary.
