## 第一批必须具体改什么

### A. 不实实测与矛盾内容

兼容性页只允许两种结果：用有输入hash、输出hash、准确引擎版本、命令、时间及检查日志的真实报告替换；或撤掉“真实机器实测/全部通过”声明并作为未验证演示，不再当证据推广。保留演示时可临时noindex并移出sitemap；这是防止错误证据传播，不是提高其他页抓取配额的技术。

Harry Potter页先纠正来源与比较断言；不要为了保留书名流量而继续暗示格式转换解除保护、自动同步进度。其他系列页是否保留按独有信息决定，已有3个规范别名先完成治理。

17篇英文页的名单在01中可搜索“英文页面的 Key Takeaways”。每页处理摘要事实、语言和正文一致性；不做只删除中文的表面修补。优先修复夹带旧容量/格式承诺的摘要。

### B. 统一工具承诺

先查以下源码所代表的实际路径，再对照生产行为：ToolPageClient.tsx、conversion-map.ts、conversion.ts、convert-handler.ts和api/convert/route.ts。正文优先采用用户能理解的能力限制，不需要向产品用户暴露所有后端细节。

| 内容 | 应达到的表述标准 |
|---|---|
| 引擎 | 不声称所有转换都走Calibre；强调当前输出能力，必要时解释“仅提取文字” |
| 保真 | 不保证TXT保留图片，不保证纯文本重建保留CSS/字体/注释；每个格式对写实际损失 |
| 批量 | beta免费、4 MB/文件、部分本地格式20个、其他当前3个的适用范围核实后统一；Pro不被描述成绕过限制 |
| 单文件 | 100 MB必须对应实际启用入口；回退和批量4 MB分开；不把最大可上传等同最大可成功转换 |
| 时间 | 秒级必须有代表实测及适用范围，否则使用不保证具体秒数的描述 |
| 删除与第三方 | 区分输入文件、输出文件、缓存、失败清理、第三方处理及保留时长；后台配置未知不承诺“立即永久删除” |

共享模板影响名单外页面，必须先列出影响集合。最小回归覆盖TXT提取、TXT合成、图像/扫描类、后端/第三方及真实西语版本，不以一个样本通过推导全站可靠。

### C. 普通链接与规范地址

- 英文和西语对应页添加可抓取的普通a链接，不只依赖语言下拉框事件或hreflang；保留独立canonical。现有/es、/es/blog、/es/guide、/es/convert入口404，不要生成指向它们的链接；不必为解决入口先新建所有西语hub。
- 样本无其他普通入口的5页：compare/bookconv-vs-calibre、compat/epub-to-mobi-on-kindle-paperwhite、es/convert/epub-to-doc、es/guide/ai-ebook-converter、es/guide/epub-vs-mobi。兼容性页先完成真实性修复，再考虑增加入口。
- 数据3个子页有来自/data的入口，但整个数据集合在样本中未发现首页路径；如果确有案例阅读场景，可从about或相关研究文章链接/data，避免全站堆链接。
- 4个旧别名：epub-to-various-other → epub-converter；lord-of-the-rings/marvel/twilight 三页 → read-epub-on-any-device。从sitemap去掉旧地址，指向等价规范目标；301前检查Bing/站外引用，不因当前Google不收录就认定无价值。
- /es/guide/azw3-vs-mobi旧404：检查/es/blog/azw3-vs-mobi的任务等价性后决定是否301；无等价替代维持404。

## 功能验证记录与通过条件

每个样本至少记录：日期、样本来源与授权、输入格式/大小/hash、目标格式、入口与批量数量、响应结果、输出hash/大小、实际打开的软件、检查内容、失败信息、是否重试。不得上传私人书籍作验证，不需付费扩大批量。

优先路线：MOBI→TXT、TXT→EPUB、FB2/HTML→EPUB、EPUB→PDF，以及已抓取未收录的西语EPUB→DOC。其余AZW3→PDF、MOBI→PDF、CBR/DJVU按既有交付保障安排验证。这里的代表路线是验证文案边界，不预设后台全部成功。

- TXT：字符编码、段落/章节分隔、文本完整性；没有图片属于格式预期。
- EPUB：目录、章节、封面、图片、脚注、样式和目标阅读器实际打开；区分文本回退能力。
- PDF：页数、页序、字体、裁切、图片、文字层/可搜索性，扫描件无OCR不得承诺可搜索。
- 流式渲染：原始完整HTML有内容；JS后主标题/正文可见；加载失败有清晰恢复方式；GSC实时测试结果另记。30页不能只据一页成功全体放行，至少覆盖每种模板及语言，并对失败页单独复测。

## 第二主页面选择与止损

候选1：/es/convert/epub-to-doc。优势是Google10/25已经抓取成功且canonical自引用，属于可针对内容/任务改善的页面；样本中无其他普通入口。依赖为确认实际DOC/DOCX交付和模板真实性，不能在输出格式不实的情况下做增长实验。

候选2：/convert/epub-to-pdf。优势是明确工具任务及较多相关内链，能提供真实分页/图片示例；但仍是已发现未收录，先排除实际转换或渲染问题。不是凭竞争词热度断言它一定带来流量。

## 观测指标、窗口与转向条件

| 指标 | 定义 | 可作出的结论 |
|---|---|---|
| 新抓取 | 同一URL的lastCrawlTime较基线更新 | Google确实再次抓取；不能等同收录 |
| 保存索引状态 | Inspection verdict与coverageState，缺失/错误单列 | 当前API记录，不等同实时浏览器测试 |
| 规范一致性 | 线上声明、sitemap目标、普通内链与Google保存canonical分别记录 | 哪个信号已对齐；不把缺失Google字段认作不一致 |
| 真实功能 | 样本转换成功且通过对应输出验收 | 该样本/条件下可用；不外推最大容量和全部格式 |
| 搜索覆盖 | 同窗口page数据与可见query,page分开，品牌/非品牌分开 | 相关搜索覆盖变化；匿名/省略查询不补成0 |
| 有效访问 | GSC点击与已有GA4真实外部访问分开；排除测试流量 | 流量变化；不以一次展示证明商业价值 |

t0为实际线上验证生效时间，排除发布日后选择完整自然日；t0+7先看部署、抓取和新错误，t0+14看相关查询覆盖及状态迁移，t0+28做等长窗口复评。因果评价仍受共享模板和其他同期变化影响。11/1 Calibre实验继续沿用原计划的前窗10/4—10/31、后窗11/2—11/29，数据可用后再评估，不用本计划重置。

转向规则：

1. 出现生产5xx/429或Googlebot访问异常证据：暂停新增SEO内容，处理实际可用性。
2. 页面可用但持续未抓取：复核GSC主机健康与普通入口；不重复提交同URL多次，不急于加字数。
3. 已抓取仍未收录：检查实际任务、近重复、规范信号及内容准确性；不要继续把发现当唯一问题。
4. 已收录无相关查询：评估需求、页面定位与竞争证据；不把索引成功当获客成功。
5. 28天低样本：报告证据不足，保留或调整假设；不得宣布Google拒绝该站或改版必然无效。
6. 事实/功能修复完成且有实质更新后，仅对少量重点页通过GSC请求索引；本次没有执行提交。IndexNow不列为Google提交方式。
