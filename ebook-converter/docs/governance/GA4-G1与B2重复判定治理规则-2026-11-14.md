# GA4 G1/B2重复判定治理规则｜2026-11-14
Owner明确裁定：否。已由G1的「逐条给采用值与理由」承接；同一错误若已使G1部分达标或不达标，本条不重复判。
执行口径：
1. G1逐条审查每个错误码的采用值、来源、理由及调用链，作为错误映射质量的主判定。
2. B2只评价G1未覆盖的剩余归因盲区，不重复对同一错误码/同一调用链扣分。
3. 若G1已将同一错误判为部分达标/不达标，B2记录“由G1承接/不重复计分”，不得再次叠加同一缺陷作为第二个独立问题。
4. B2仍可报告总体UNKNOWN比例作为观察指标，但不得仅凭同一批已被G1判定的错误重复升级为额外FAIL。
5. 如G1没有可追溯的逐条证据，则B2维持待核查，不擅自豁免。
