## 一、结论摘要（先读这五条）

1. **工具型竞品的共同公式 = 「结构化事实块 + 具体数字 + 整块可摘录」**，内容深度普遍只有约 250–600 词（估算）——它们赢在摘录单元，不在深度。⚠️ 归因声明：这是可操作假设（与 Bing AI 引用机制观察一致），非已证因果；mediaconvert 的 SERP 位次也可能受域权重/外链影响。我方 31/31 GEO PASS 的深度是护城河，但缺摘录单元。
2. **全站最值得抄的一个模块 = Convertio 的「About formats」深度段**：每种格式一段 300+ 词的百科级论述（历史/版本/标准组织/能力边界）+ Developer / Initial release 元数据行 + W3C/ISO/Wikipedia 权威外链。这正好是我方 `/formats/*` 17 页暗页（0 曝光）应有的样子。
3. **榜单型竞品（gitnux/zipdo）的护城河 = 方法论与 E-E-A-T 外壳**：4 步排名方法论、Editor's top 3 picks、评分表（Features/Ease/Value）、作者 + fact-checker 署名、联盟披露。内容实为 AI 生成质感，但结构完全对齐 E-E-A-T。
4. **竞品普遍弱点（= 我方机会）**：无 troubleshooting、无质量检查清单、无"When 转换"场景判断、无作者/日期署名、FAQ 浅且雷同、非电子书垂直（多数是全格式通用工具）。我方内容缺口分析里的 When/Checklist 节恰好竞品全部缺失。
5. **数字对比诚实问题**：convertio 免费 1GB、anyconv 100MB、miconv 75MB、megaconvert 25MB——我方 10MB 是全场最小。参照动作不是改数字（诚实铁律），而是把「10MB covers virtually all novels」上移到 hero 第一屏，正面对冲。

## 二、逐竞品优弱点实测表

### 1. Convertio（convertio.co/epub-pdf）— 语义深度标杆

| 维度 | 实测 |
|---|---|
| 结构 | How-to 3 步 → About formats（每种格式 300+ 词百科段）→ 6 条 FAQ |
| 优势 | ① **格式百科深度全场第一**：EPUB 段涵盖 IDPF→W3C 沿革、OEBPS 前身、ZIP/XHTML 内部结构、EPUB 3 能力（MathML/media overlays/无障碍）、reflowable 模型优点；② 元数据行 **Initial release: October 2007**；③ 权威外链（W3C、ISO 32000、Wikipedia）；④ 隐私数字具体：「上传后立即删除 + 结果 24h 内自动删除」；⑤ 页面宣称 1GB 上限（⚠️ 免费/登录档未区分，引用前需再核） |
| 弱点 | FAQ 通用（6 条且与页面深度不匹配）；无对比表、无 troubleshooting、无作者/日期；格式选择器是 300+ 格式长列表（对垂直用户是噪音） |
| 我方参照 | `/formats/*` 17 页照此标准扩写 = **暗页复活的第一杠杆**；convert 页的 What is X 节补 Developer/Initial release 元数据行 |

### 2. AnyConv（anyconv.com/epub-to-pdf-converter）— Key facts 事实卡标杆

| 维度 | 实测 |
|---|---|
| 结构 | 3 步 How-to → What is EPUB（含 How to open）→ **Key facts 事实卡** → Useful links → What is PDF（同构） |
| 优势 | ① **Key facts 卡**：Full name / Extension / MIME type / Developed by / Initial release 五行——AI 摘录成本最低的单元；② 「How to open X files」节（我方缺失的 POST 场景）；③ 每格式双向转换入口 + Wikipedia 外链；④ 100MB 上限；⑤ "download link is private and only works on your device" |
| 弱点 | 正文约 400 词、无 FAQ、无对比表、无 troubleshooting、无作者 |
| 我方参照 | M16 事实卡注入的**直接模板**（31 convert 页 5 行事实表，数据静态写死） |

### 3. mediaconvert（mediaconvert.org/epub-to-pdf）— SERP 双词 #1 的轻内容打法

| 维度 | 实测 |
|---|---|
| 结构 | 工具在首屏 → 3 步 How-to → **EPUB vs PDF 对比表**（Full name/Type/Compression/Best for 四行）→ 7 条 FAQ → **embed widget 代码块** |
| 优势 | ① 对比表精炼且每行可摘录；② FAQ 7 条全部直击搜索意图（质量损失/区别/免费/隐私/设备/耗时/其他格式）；③ **embed widget = 天然外链机器**（sandboxed + attribution link 强制保留）；④ 隐私表述具体（加密传输 + 24h 删除 + never share/sell/look）；⑤ 格式枢纽页 `/formats/epub` 聚合全部 EPUB 转换对 |
| 弱点 | 正文约 500 词；无 When-to-convert 场景判断、无 checklist、无 E-E-A-T 信号；对比表只有 4 行（我方可做 8–10 行碾压版） |
| 我方参照 | embed widget 列入 backlog（P2，工程 1–2 天）；EPUB vs PDF 对比表结构可直接借入 `/blog/epub-vs-mobi` 系 |

### 4. MegaConvert（megaconvert.io）— 信任徽章 + 内链网格标杆

| 维度 | 实测 |
|---|---|
| 结构 | 统计徽章（12.9K files converted / 500+ formats / 99.9% uptime）→ How it works → Why（6 卡）→ **按类别分组的全量内链网格**（12 类，每类 6+ 对）→ REST API（cURL 示例）→ 5 条折叠 FAQ |
| 优势 | ① 内链网格按用户语言分组（E-Books 📚 / Documents 📄…），爬虫与用户都能高效分发权重；② API 文档直接放转化页（开发者即买家）；③ 24h 删除 + SSL 表述统一出现在每个模块 |
| 弱点 | **零电子书垂直内容**——没有任何格式教育内容，FAQ 折叠且通用；12.9K 计数器不可验证（我方 K1 已主动删除同类假计数器，勿学）；内容与 ebook 搜索意图错配 |
| 我方参照 | `/convert` 页与首页的转换对分组方式可借鉴（我方现在按格式分）；API 段落对 /pricing 的呼应 |

### 5. MiConv（miconv.com/epub-to-pdf）— at-a-glance 标杆

| 维度 | 实测 |
|---|---|
| 结构 | **At a glance 参数块**（🔁转换对 / ⏱平均 20 秒 / 💳免费 / 📂类别 / ✳️扩展名 / 📏75MB / 👩‍💻全平台）→ About EPUB → About PDF（各 1 段 + converter 内链） |
| 优势 | 页面第一屏就把全部决策参数给完——**AI 与用户都不用滚动**；75MB 上限具体 |
| 弱点 | 正文约 250 词，全站内容最薄；无 FAQ、无对比表、无 E-E-A-T |
| 我方参照 | at-a-glance 行加到 convert 页 hero 下方（"10MB · ~30s · browser-based · 1h auto-delete"，**每个数字先核代码再写**） |

### 6. 榜单内容型（gitnux / zipdo / wifitalents / bestapptips）— GEO 榜单词的守门人

| 维度 | 实测 |
|---|---|
| 结构（gitnux/zipdo 同构） | 4 步排名方法论 → Editor's top 3 picks（各配 "Built for / Fits when" 场景句）→ 10 工具评分对比表（Overall/Features/Ease/Value）→ 逐工具 Pros/Cons/tradeoff → 联盟披露 |
| 优势 | ① **方法论声明**（Feature Verification → Review Aggregation → User Modeling → Human Editorial）直接回应 E-E-A-T；② 署名制（zipdo：Author Andrew Morrison + Fact-checker Kathleen Morris）；③ 「Best for: fits when…」场景句式把工具和人群绑定，是 AI 引用率高的句式；④ bestapptips（中文）开场先给「还需要转吗」判断表——**决策前置**，我方 When 节同款思路 |
| 弱点 | AI 生成质感重（wifitalents 出现与电子书无关的 "regulated baselines" 模板残留——**模板化批量生产的实证**）；联盟利益驱动；对 BookConv 这类免费在线工具多数仅一句带过 |
| 我方参照 | `/guide/best-ebook-converter`（97 词）扩写至 1500+ 的**结构模板**：方法论 + top 3 场景句 + 评分表 + 署名；「为什么免费还够用」是我方对榜单的独特角度（竞品全部在卖工具） |
