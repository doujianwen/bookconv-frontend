五、本轮我自己的 4 次判据 bug（元教训）

① 抽样偏差：只看 tail -8 见到 exit 0 就断言「audit.sh 恒绿」，实际第 204 行有 exit 1。判退出码逻辑必须 grep 全文。
② 路径基准错：判据把 7 个真实存在的脚本误报「未入库」（假失败）⇒ 改用 git ls-files -z 作单一数据源。
③ Windows fork EBUSY：Node 内 fork git 恒 status=null ⇒ 改为 stdin 接清单，拿不到就 exit(2)。
④ git -C 陷阱：CI 里上一行已 cd ebook-converter，不加 -C .. 则全假失败。若不做反向验证，我就是亲手造了一个假门禁。
