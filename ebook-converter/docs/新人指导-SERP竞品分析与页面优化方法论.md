# 新人指导 — SERP 竞品分析与页面优化方法论

> **用途**：拿到一批关键词后，如何在 Google 上逐批查询、记录竞品、分析对方排名优势、对照我们的页面找差距并产出改进建议。
> **适用场景**：关键词排名追踪表（`geo/关键词URL排名追踪表-*.md`）中的任意一批词。
> **前置条件**：先读 `新人培训-Google-Cloud与GSC授权.md`（会拉 GSC 数据）+ `新人指导-内链优化规则.md`（懂内链规范）。

---

## 0. 一句话流程

**选词 → Google 搜索 → 记录 Top10 → 深度分析 Top3 → 对照我们的页 → 产出改进清单**

---

## 1. 分批策略（不要一次全搜）

关键词追踪表通常有 60-100 个词。一次全搜既慢又难聚焦，按优先级分 3 批：

| 批次 | 范围 | 词数 | 目的 | 时机 |
|---|---|---:|---|---|
| **第 1 批** | P0/P1 核心追踪词 | ~15 | 最大杠杆先做（mobi→epub / azw3 / zip / txt 簇） | 立即 |
| **第 2 批** | P2 监测词 + 缺口词 | ~15 | 看竞品怎么承接这些意图，为建页/优化找方向 | 第 1 批完成后 |
| **第 3 批** | 用户意图词（GSC 暂无数据） | ~20 | 高量级词（djvu-to-pdf / pdf-to-epub 等），看 SERP 格局 | 按需 |

**选词原则**：
- 同一簇的词放一起搜（如 mobi→epub 簇 18 个词一次搜完），方便交叉对比
- 先搜已有 GSC 展示的词（有数据支撑），再搜纯意图词
- 缺口词（站上无页）单独搜——目的是看 SERP 门槛，决定是否建页

---

## 2. 分析维度（6 项固定清单）

每个竞品页都查这 6 项，形成标准化对比：

### 2.1 SERP 特征
- 有没有**精选摘要**（Featured Snippet）？是谁的？什么格式（段落/表格/列表）？
- 有没有 **People Also Ask**？记下前 3-4 个问题（这些就是 FAQ 目标）
- 有没有**图片包 / 视频包 / 知识面板**？
- **行动**：有精选摘要 → 我们要抢（用同格式但更优内容）；有 PAA → 我们的 FAQ 要覆盖这些问题

### 2.2 内容深度
- **字数**：竞品页大约多少字？（工具页 500-1000 字 / 内容页 1500-3000 字 / 综合指南 3000+ 字）
- **H2/H3 层级**：覆盖了哪些子话题？（记下标题大纲）
- **结构化元素**：有没有对比表 / 步骤列表 / FAQ / 代码块 / 截图？
- **行动**：如果竞品 2000 字我们 800 字 → 内容深度是主要差距

### 2.3 标题策略
- **title 标签**怎么写的？关键词在第几位？用了什么修饰词（Free / Online / Best / No Install）？
- **H1** 和 title 一样还是不同？
- **Meta description** 怎么写的？有没有 CTA？
- **行动**：如果竞品标题是 "Free MOBI to EPUB Converter Online — No Install" 而我们是 "MOBI to EPUB" → 标题优化是快赢

### 2.4 内容格式
- **工具页**（页面中心是一个转换器 widget）
- **内容页**（长文 + CTA 引导到工具）
- **混合页**（工具在上半屏，内容在下半屏）
- **行动**：如果 Top 5 全是混合页而我们只有工具页 → 缺内容层；如果全是工具页而我们内容太多 → 可能过度

### 2.5 差异化卖点
竞品写了什么我们没有的？逐条记录：
- 隐私/安全承诺（SSL、自动删除文件、不上传服务器）
- 批量转换入口
- CLI / API 文档
- 设备兼容表（哪些 Kindle / Kobo / Nook 支持什么格式）
- 对比表（vs Calibre / vs CloudConvert / vs Zamzar）
- 用户评价 / 信任徽章
- DRM 说明
- **行动**：把竞品有、我们没有的列成清单，按性价比排序补上

### 2.6 URL 结构
- 是**子域**（converter.cloudconvert.com）还是**子目录**（cloudconvert.com/mobi-to-epub）还是**独立域名**（mobitoepub.com）？
- 路径深度：几层？
- **行动**：记录但通常不改我们的 URL 结构——这是架构决策，不是内容优化

## 3. 操作步骤（照做即可）

### 步骤 1：搜索并记录 SERP

```
对每个关键词：
1. 用 WebSearch 搜索（英文搜索，主流量在英文）
2. 记录 Top 10 有机结果：位置 / URL / 标题 / 描述
3. 记录 SERP 特征：精选摘要？PAA？图片包？视频包？
4. 标注我们的页面是否出现、在第几位
```

**输出格式**（每个关键词一行）：

| 位置 | URL | 域名 | 标题 | 类型 | 我们的？ |
|---:|---|---|---|---|---|
| 1 | ... | ... | ... | 工具页/内容页/混合 | ❌ |
| 2 | ... | ... | ... | ... | ❌ |
| ... | | | | | |
| 8 | bookconv.com/convert/mobi-to-epub | bookconv | ... | 工具页 | ✅ |

### 步骤 2：深度分析 Top 3 竞品

```
对 Top 3 竞品页：
1. 用 WebFetch 抓取页面内容
2. 按 6 维度逐项分析（§2）
3. 记录到竞品分析卡
```

**竞品分析卡模板**（每个竞品一张）：

```markdown
### 竞品 #[N]：[域名] — [URL]
- **位置**：#[N]
- **类型**：工具页 / 内容页 / 混合页
- **字数**：约 [X] 字
- **标题**：[完整 title]
- **H1**：[完整 H1]
- **H2/H3 大纲**：
  - H2: ...
  - H2: ...
  - H3: ...
- **结构化元素**：□ 对比表 □ 步骤列表 □ FAQ □ 代码块 □ 截图 □ 视频
- **Schema**：□ FAQPage □ HowTo □ Article □ Breadcrumb □ 无
- **差异化卖点**：
  - [卖点1]
  - [卖点2]
- **SERP 特征**：□ 精选摘要 □ PAA □ 图片包 □ 视频包
- **我们缺什么**：[具体差距]
```

### 步骤 3：对照我们的页面

```
对我们的目标页：
1. 用 WebFetch 抓取我们的页面内容
2. 同样按 6 维度分析
3. 与 Top 3 竞品逐项对比
4. 列出差距清单
```

### 步骤 4：产出改进清单

```markdown
## 改进清单：[关键词] → [我们的 URL]

| 优先级 | 改进项 | 竞品有 | 我们现状 | 动作 | 预期效果 |
|---|---|---|---|---|---|
| P0 | 标题加修饰词 | "Free ... Online — No Install" | "MOBI to EPUB" | 改 title | 提升CTR |
| P0 | 加对比表 | vs Calibre / vs Zamzar | 无 | 新增段落 | 增加停留时间 |
| P1 | 加 FAQ | 4 条 PAA 问题 | 3 条 FAQ | 补 1 条 | 抢精选摘要 |
| P1 | 加设备兼容表 | Kindle 机型 × 格式 | 无 | 新增表格 | 差异化 |
| P2 | 加隐私承诺 | "Files deleted in 1h" | 无 | 新增段落 | 信任感 |
```

## 4. 交叉分析（跨关键词找规律）

单批词分析完后，做一次交叉总结：

### 4.1 竞品格局
- **谁在霸屏**？记录反复出现的域名（如 Calibre / CloudConvert / Zamzar / Online-Convert / Convertio）
- **他们用什么策略**？工具页为主？内容页为主？混合？
- **DA 门槛**：Top 10 竞品的域名权威大约什么水平？（诚实：我们拿不到精确 DA，但可以看域名知名度和页面内容深度推断）

### 4.2 SERP 特征规律
- 哪些词有精选摘要？什么格式？→ 抢摘要机会
- 哪些词有 PAA？问题是什么？→ FAQ 目标
- 哪些词有视频包？→ 是否需要加视频
- 哪些词 SERP 全是工具页（无内容页）？→ 内容页有机会超车

### 4.3 内容深度基准
- Top 5 竞品的平均字数是多少？→ 我们的目标字数
- 哪些子话题被多个竞品覆盖？→ 必须有的段落
- 哪些子话题只有 1 个竞品覆盖？→ 差异化机会

### 4.4 我们的定位
- 哪些词我们完全没排名？→ 要么建页，要么放弃（看 ROI）
- 哪些词我们排名差但竞品不强？→ 优化机会
- 哪些词竞品全是 DA 80+ 大站？→ 短期不打，等权威起来

## 5. 工具能力与限制（诚实版）

### 能做的
- **WebSearch**：搜索 Google，拿到 SERP 结果列表（位置 / URL / 标题 / 描述）
- **WebFetch**：深入抓取竞品页面的实际内容，分析结构、字数、标题层级
- **GSC API**：拉取我们的真实展示/位置/点击数据（见 `geo/GSC报告操作说明.md`）

### 做不到的（需外部工具补充）
- **反向链接 / DA / DR**：需要 Ahrefs / SEMrush / Moz。如果你有这些工具的截图或导出数据，补进分析会更完整
- **精确搜索量**：GSC 只给展示量（我们自己的），不给市场总量。需要 Google Keyword Planner 或 Ahrefs
- **个性化 SERP**：搜索结果可能因地区/语言/登录状态不同有差异。我们用英文搜索（主流量在英文），结果接近美国默认 SERP
- **实时排名追踪**：GSC 数据有 2-3 天延迟；要实时排名需第三方工具（如 Ahrefs Rank Tracker / Semrush Position Tracking）

每批关键词分析完后，产出一份报告，存放于 `geo/` 目录：

## 7. 常见误区（新人必读）

1. **不要只看谁排第 1**——要看 Top 10 整体格局。第 1 可能是 DA 90 的大站我们短期打不过，但第 5-10 可能是 DA 30 的小站我们可以超。
2. **不要只分析工具页**——很多词的 SERP 里内容页（博客/指南）排名比工具页好。Google 认为用户要"了解"而非直接"转换"。
3. **不要忽视 PAA**——People Also Ask 里的问题就是 FAQ 的目标，覆盖它们能抢精选摘要。
4. **不要照抄竞品内容**——分析对方的结构和卖点，但用我们自己的数据和角度写。E-E-A-T 要求原创性。
5. **不要根据 1 次展示的词做重大决策**——GSC 单次展示词位置波动极大，统计意义不足。
6. **改进清单要可执行**——不要写"提升内容质量"这种废话。要写"在 H2 'How to convert' 下新增 3 步操作列表 + 1 张对比表"。
