## 0. 设计原则（防"建目录冒充积累"）

本索引刻意**不建 20 个空目录**。理由与代价：

| 原则 | 说明 |
|---|---|
| **一个索引 + 重要案例独立文档 + 原始证据链接** | 20 个分类是**检索维度**，不是 20 个物理目录。空目录会让"素材积累完成"变成自欺。 |
| **素材必须是真实过程的副产品** | 不为写课而额外开发。任何分类下没有真实案例就是空的，如实标注"无素材"。 |
| **不复制原始证据** | 素材库指向原始文件（路径/链接），原始文件是唯一真相。 |
| **状态可降不可升** | RAW → CURATED → VERIFIED → TEACHING_READY 只在证据达标时晋升；证据失效必须降级。 |
| **公开性单独判定** | "有教学价值"与"可以公开"是两件事，见 §4。 |

## 3. 素材状态机

```
RAW ──整理──> CURATED ──证据复核──> VERIFIED ──教学设计──> TEACHING_READY
 ↑                                                              │
 └──────────────── 证据失效 / 结论被推翻 → 降级并记勘误 ─────────┘
```

| 状态 | 达标条件 |
|---|---|
| RAW | 存在原始记录，未整理 |
| CURATED | 结构完整、可直接阅读 |
| VERIFIED | 有**可复核证据**（命令输出 / 文件哈希 / 数据快照 / 复现步骤），且证据与结论同时可见 |
| TEACHING_READY | VERIFIED + 有明确教学点 + 有习题/讨论设计 + 公开性判定完成 |

**禁止**：未验证的经验标 VERIFIED；把"我说过"当证据。

## 4. 公开性分级

| 级别 | 含义 | 处置 |
|---|---|---|
| ✅ 可公开 | 无敏感信息 | 直接用于课程/文章 |
| ⚠️ 脱敏后可用 | 含路径/成本/内部流程 | 删除敏感值后使用，保留方法 |
| 🔒 仅内部 | 含服务器/密钥/内部策略 | 不进任何对外材料 |
| ❌ 不可公开 | 含用户数据/真实客户名/已泄露凭据 | 永久隔离 |

**明确列入 🔒/❌ 的内容**
- 生产服务器 IP / 主机名（**本文档不记载，见内部凭据库**）、SSH 密钥路径、`INTERNAL_SECRET`、代理端口
- 客户真实品牌名（Notion 已代号化 Client-A/B/C，对照表不入库）
- 未脱敏 GA4/GSC 原始导出（含 query 全量）
- 真实用户上传文件、任何个人信息
- 含 token 的历史文件（已删，git 历史仍在）
