### 红队回执 · 11/5 SEO 核查交付 · L3

**断言**：#1 5 个目标页全部 200、自引用 canonical、在 sitemap、无 noindex；#2 头部两页缺 `es` hreflang 属技术缺陷；#3 GSC 索引状态权限可用、6 页状态可直接采信；#4 `inSitemap` 字段空 = 不在 sitemap；#5 `epub para doc` 118 曝光落英文页，且两窗 116→118 是增长；#6 Topic Portfolio 仍 1M (Sep)；#7 今日任务「已完成」可被他人复核。

**攻击（逐条设计可失败的实验）**：
1. Vercel 对不存在路径可能返 200+兜底 HTML ⇒ 造不存在的 slug 做负对照 + 比对 `X-Matched-Path`、title/H1。
2. 若 `/es/blog/best-ebook-reader-apps`、`/es/convert/epub-to-pdf` 存在且可索引，则「缺 es」就是漏标 ⇒ 直接 curl + grep sitemap。

4. 找一个已收录且线上 sitemap 明确命中的页，看 API 字段是否仍空 ⇒ 用 `/convert/epub-to-doc` 做反例。
5. 窗口错/维度顺序错/旧快照混入都会让 118 失真 ⇒ 脚本硬断言窗口字段、锚点 query/page、rows 数；另比 10/25 快照窗口。
6. 缓存 DOM / 登录过期会读到假 Sep ⇒ reload 二次读取 + `hasSignIn`/`hasOct` 双判据。
7. 「文件存在」不等于「实测跑通」；分母是否含未完成项；任务板是否回读 ⇒ 核对证据形态、分母、同步三项。
