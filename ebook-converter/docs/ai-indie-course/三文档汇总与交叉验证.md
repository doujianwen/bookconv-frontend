## 1. 三文档核心结论

### 1.1 PRD（PM 许清楚 · v1.1）
- **一句话价值主张**：跟着一个真实上线的产品，把从想法到有人用的六个阶段走完一遍——包括没人用的时候怎么办。
- **5 个不可复制支点**：①真实项目+真实账本（一年运营史）②真实工程复杂度（Next.js 16+BullMQ/Redis+S3+Sentry+payments）③转换纠察层 `verifyConversion()`（已落地、非待办）④诚实失败数据（287 展示/0 点击/25 用户）⑤六阶段可迁移方法论（不绑工具版本）。
- **MVP 范围（7 进 v1 / 5 进 v2，RICE 排序）**：M1 Spec 驱动开发(15.0) / M2 六阶段主线(10.0) / M3 AI 代码安全与验收(8.0) / M4 上线后增长诊断(7.2) / M5 零基础环境工具链(7.0) / M6 真实项目从零重跑(6.0) / M7 图文速查手册(5.0)。
- **定价**：国内早鸟 ¥299 / 标准 ¥499；海外早鸟 $79 / 标准 $99。建议 7 天无理由退款。
- **AC-6 样本书闸门**：首批 30 页 + Project Gutenberg 公共领域书目 + 人工审核 + GSC 观察两周再扩量；样本书不齐不得进 Phase 4。
- **待你拍板**：Q2 诚实账本定位口径 / Q3 M12 轻量陪跑。

### 1.2 架构（高见远）
- **17 章大纲**，映射专家团 6 Phase（需求→调研→Spec→设计→开发→测试→部署→增长）。
- **演示产物推荐①「转换兼容性实测报告页生成器」**：唯一 6/6 覆盖全流程、零新增依赖、录制可控、命中 bookconv 四项核心资产（单源数据+index 注册+sitemap 派生+SEO）。破解 Google 规模化内容政策的方式是「每页承载机器实测独有数据，而非 LLM 洗稿」。
- **锁定依赖**：Next 16.2.10 / React 19.2.4 / Tailwind 4.3.2 / **lucide-react 1.24.0（锁死不升）** / next-intl 4.13.2 / zod 4.4.3 / jest 30.4.2 / playwright 1.62.1 / Vercel。
- **ADR**：001 锁 lucide；002 demo 选型；003 API 版本前缀存量偏差（存量不改、新增遵循，当真实案例讲）。
- **事实修正（课程文案必须改）**：Next.js 是 16 非 15；`verifyConversion()` 已落地（conversion-verifier.ts:162，被 queue.ts/conversion.ts 调用）非待办。
- **6 个真实缺陷（D1–D6）**：死代码 `providedKey`、非常量时间比较、`any` 类型擦除、12 文件 emoji 违规、`queue.ts` 661 行超约束、测试路由进生产——全带行号，作「代码审查」环节素材。

### 1.3 设计（颜好看）
- **双寄存器**：Brand（Landing/定价/讲师页，独特性优先）/ Product（学习端，熟悉感优先，Linear/Notion/Frontend Masters 级）。
- **品牌声音**：工程手册 · 车间台灯 · 蓝晒图纸。强调色 = 普鲁士蓝 `#14489C`（非 Indigo，无紫向偏移），琥珀 `#B45309` 次色。
- **字体 4 族**：Archivo(display) / Inter(body) / Noto Sans SC(cn) / JetBrains Mono(mono)——视频↔网页视觉连续性。
- **Token 全锁定 + 双主题**：`data-theme` + SSR 防 FOUC；深色默认 `/learn/*`，亮度递进表达层级不靠阴影。
- **录屏规范（核心交付）**：1920×1080 / 30fps / 8Mbps / 单节 ≤12min；IDE 锁 GitHub Dark Default；三档固定布局；`lesson-XX.chapters.json` 作为视频↔图文双形态唯一连接点。
- **P0 门禁全绿**：emoji 扫描 PASS / JSON valid / 对比度全 PASS / 间距全 4 倍数。
