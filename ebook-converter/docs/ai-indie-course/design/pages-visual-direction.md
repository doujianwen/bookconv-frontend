## 一、课程 Landing（Brand 寄存器 · Light 主题 · VARIANCE 7 / DENSITY 4）

### 整体判断

这是一门卖「能不能真的做出东西」的课，所以 Landing 的全部说服力来自**证据密度**，不是文案修辞。视觉策略一句话：**把成品摆在桌上，让人自己判断**。

### 1. 顶栏（64px，sticky，滚动 >80px 时加 `border-bottom: 1px --border`）

左：课程标识（文字标识，Archivo 590 / 20px，无图形 Logo）。
中：`课程大纲` `谁适合` `讲师` `常见问题`（16px / --muted，hover → --fg）。
右：`免费试看`（Ghost）+ `立即购买`（Primary）。
移动端：右侧只留 `立即购买` + `menu` 图标抽屉。

### 2. Hero（高度 ≈ 58vh，`padding-top: 88px`，**非对称**，绝不居中）

背景：`--bg` 纯色 + `.blueprint-grid`（40px 蓝晒网格，opacity 内置 0.04）。**无渐变、无光晕、无 3D 图形。**

```
┌───────────────────────────── 1200px ─────────────────────────────┐
│  ← 7/12 左对齐 ──────────────┐  ┌── 5/12，margin-top:40px 错位 ──┐ │
│                              │  │                                │ │
│  一行 meta（mono 13px）       │  │   [ 证据堆叠区 ]                │ │
│  12 个视频节 · 12 篇图文 · …  │  │   三张真实截图错落叠放：        │ │
│                              │  │   ① bookconv.com 真实首页      │ │
│  H1（display 60/1.1/-0.02em）│  │      （最底层，旋转 -3°）       │ │
│  「跟着做完，你会有两个        │  │   ② Cursor 真实对话窗口        │ │
│    真实上线的站」             │  │      （中层，旋转 0°，前移）    │ │
│                              │  │   ③ Vercel Deployment 成功面板 │ │
│  副文案（17px/1.75/--muted，  │  │      （最上层，旋转 +4°，右下） │ │

- **accent 配额**：Hero 内只用 2 处 —— `立即购买` 按钮 + Vercel 面板截图里那个天然的绿色对勾（不算，属截图内容）。其余全中性。
- 移动端：证据堆叠区改为**横向可滑动的三张卡**（scroll-snap），旋转归零，H1 降到 `clamp(32px,8vw,40px)`。

### 3. 「谁适合 / 谁不适合」（反筛选，比"适合人群"更建立信任）

双栏对照，中间 1px `--border` 竖线。左栏 `circle-check` + `--success` 图标，右栏 `x` + `--muted` 图标（**不用红色**，不制造对立）。
每栏 4 条，每条一句人话（例：「你有一个想法，但每次开到第三天就卡在部署」）。
**不用卡片，不用图标网格。**

### 4. 「你会亲手做出什么」（核心证据区）

两个真实项目，各占一个横向大区块（不是三列卡片网格）：

```
┌─ 项目一 ────────────────────────────────────────────┐
│  左 5/12：项目名 + 一段"它解决什么" + 真实上线地址   │
│           （链接可点，带 external-link 16px 图标）   │
│           下方一行 mono 真实指标                     │
│  右 7/12：真实站点截图（浏览器 chrome 简化版包装：   │
│           顶部 32px 灰条 + 三个 8px 圆点，radius 10）│
└─────────────────────────────────────────────────────┘
项目二：左右**互换**（打破重复节奏，VARIANCE 7 的落点）
```

### 5. 课程大纲预览

**不用卡片网格**，用可展开的模块表（与章节列表页同构，让学员提前熟悉界面）：
每个模块一行 —— mono 模块号 + 模块名 + 「7 节 · 68 分钟」 + `chevron-down`。展开后是 lesson 行（免费试看的节，标题右侧带 `play-circle` + 「试看」pill）。
展开动画 `320ms --ease-out-soft`，只动 `opacity` + `transform`。

### 6. 「方法论骨架」（MVP 专家团 6 Phase）

横向时间轴，不是六张卡片。一条 2px `--border` 横线，六个节点（12px 圆点，当前/关键节点用 `--accent`），节点下方竖排文字。移动端转 90° 变竖向时间轴。

### 7. 讲师与真实数据

左侧一张真实照片（不是插画、不是头像 emoji），右侧三行履历 + 一个**真实数据表**（不是大数字网格）：
用 `divide-y` 两列表：指标名 / 数值（mono，tabular-nums）。数据必须有出处标注（如「Google Search Console，2026-08」）。
**禁止**「10000+ 学员信赖」这类无源数字。

### 8. 免费试看

页面内嵌真实播放器（不是弹窗、不是封面图占位），下方一行三个可切换的试看节标题。**这是全页第二处 accent 配额**——当前选中的试看节标题着 `--accent`。

### 9. 定价（≤3 档，认知负荷规则）

两档：`标准`（视频 + 图文 + 仓库）/ `进阶`（+ 1v1 项目 review）。
表格式对比，不是三张彩色卡片。推荐档只用 1px `--accent` 边框 + 顶部一行小字「多数人选这档」，**不用彩色徽章、不用缩放放大**。

### 10. FAQ

手风琴，8–10 条**真实顾虑**（「零基础是不是真的能跟上」「AI 模型换了课程会过时吗」「不会英语行不行」）。
`chevron-down` 旋转 180°，`140ms`。

### 11. 尾部 CTA

重复主 CTA，不加新信息。背景切 `--surface`，上方 1px `--border`。**不做全屏渐变收尾区。**

### Landing 明确禁止清单

section 上方的 `CURRICULUM` / `PRICING` 小型大写标签、`01 · 关于` 编号标记、抽象 3D 图形、粒子背景、数字滚动动画、"开启你的 AI 之旅"类文案、任何 emoji。

## 二、章节列表页（Product 寄存器 · Light 主题 · VARIANCE 4 / DENSITY 6）

### 整体判断

学员每天来这里做的唯一决策是「我上次学到哪，下一步点哪」。所以这一页的设计目标是**扫描效率**，不是美观度。DENSITY 6 意味着：**禁止通用卡片容器**，用 `divide-y` 行式列表 + 负空间分组。

### 布局

```
┌─ 顶栏 64px（同 Landing，但右侧换成头像 + 进度） ──────────────┐
├────────────────┬──────────────────────────────────────────────┤
│ 左 240px sticky│  右 主区（max 840px，左对齐，不居中）          │
│                │                                              │
│ 课程名          │  模块 01 ─────────────────────────── 5/7 节  │
│ （2xl / 590）   │  MVP 是什么，以及为什么你上次失败了            │
│                │  ▔▔▔▔▔▔▔▔▔▔▔▔░░░░░░░  ← 2px 进度条          │
│ 环形进度        │  ┌────────────────────────────────────────┐  │
│ 68px 环         │  │ [done] 01 从一个想法到一句话   视频  08:12 │  │
│ 中间 mono 42%   │  │ [done] 02 用 AI 拆需求         图文  06 分 │  │
│                │  │ [now ] 03 写第一份 PRD         实战  14:30 │  │← current
│ [ 继续学习 ]    │  │ [todo] 04 …                    视频  09:04 │  │
│  Primary 全宽   │  │ [lock] 05 …                    实战  16:22 │  │
│                │  └────────────────────────────────────────┘  │
│ ─ 资料下载      │                                              │
│ 项目仓库        │  模块 02 ──────────────────────────  0/6 节  │
│ 提示词合集      │  …                                           │
│ 检查清单        │                                              │
└────────────────┴──────────────────────────────────────────────┘
```
> 上图 `[done] [now] [todo] [lock]` 仅为 ASCII 示意占位，实现时一律替换为 Lucide 图标：
> `circle-check`(success) / `circle-dot`(accent) / `circle`(meta) / `lock`(meta)，统一 20px。

### Lesson 行细节

- 高度 **56px**，`grid-template-columns: 20px 1fr auto auto`，gap 12px，padding 0 20px
- 分隔：`border-bottom: 1px var(--border-soft)`，**模块之间用 48px 负空间分组，不用卡片包裹**
- 序号：mono 13px `--meta`，`tabular-nums`
- 标题：16px / `--weight-emphasize` / `--fg`；已完成的节标题降为 `--muted`（视觉上"沉下去"）
- 类型 pill：1px 边框、`--radius-pill`、12px、字距 0.02em、**只描边不填色**，颜色取 `--track-*`
- 时长：mono 13px `--meta`，`tabular-nums`（保证纵向对齐成一列）
- hover：整行 `background: var(--surface-warm)`（140ms），最右端淡入 `继续 →` ghost 按钮
- current 行：`background: var(--accent-wash)`，图标 `circle-dot` 着 `--accent`
- locked 行：整行 `opacity: 0.55`，点击不跳转而是底部升起购买条

### 模块头

一行：mono 模块号（`--meta`）+ 模块标题（20px / 590）+ 右侧「5/7 节 · 48 分钟」（14px `--meta`）+ `chevron-down`。
下方紧贴一条 **2px 全宽进度条**（`--progress-rail` 底，`--progress-fill` 填充）。**不显示百分比数字**，悬停才出 tooltip。

### accent 配额自查

整页可见 accent 只有 2 处：左栏 `继续学习` 按钮 + current 行。所有 `circle-check` 用 `--success` 且统一 20px，视为状态图标不占配额，但**必须同色同尺寸**，禁止彩色泛滥。

### 五态

| 态 | 表现 |
|---|---|
| Loading | 7 行 skeleton，**复用真实 56px 行高**（防 CLS），微光扫过 1.4s |
| Empty | 仅在"我的课程"为空时出现：`book-open` 48px `--meta` + 「你还没有开始任何课程」+ `去看课程大纲` Secondary |
| Error | `triangle-alert` 24px `--danger` + 具体错误（「进度同步失败，你的本地记录已保留」）+ `重试` Secondary |
| Populated | 如上 |
| Edge | 超长节标题 → 单行 `text-overflow: ellipsis`，hover 出 title tooltip；模块 >15 节 → 默认折叠只展开当前模块 |

### 移动端（<768px）

左栏收为顶部 sticky 条（课程名 + 细进度条 + `继续学习` 文字按钮）。
Lesson 行高 **64px**，类型 pill 与时长换到标题下方第二行（14px），保证触摸目标 ≥44px。

## 三、单节播放页（Product 寄存器 · **Dark 主题默认** · VARIANCE 4 / DENSITY 5）

### 整体判断

这一页要同时装下「视频」和「图文」，处理不好就是视频上面、文章下面两个各自为政的区块。**解决方案是「关键节点时间轴」这一个部件**——它既是视频的章节导航，又是图文的目录锚点，把两种形态缝在一起。

Dark 主题默认的理由：学员的另一半屏幕是 IDE（GitHub Dark Default），网页与 IDE 同色系时视线切换无痛感。

### 布局（≥1280px 三栏）

```
┌─ 顶栏 56px：← 返回大纲 | 模块 03 · 第 2 节 | 主题切换 ─────────────┐
│  ▔▔▔▔▔▔▔▔▔▔░░░░░░░░░░  ← 2px 阅读进度条（跟正文滚动，非页面滚动）│
├──────────┬──────────────────────────────────┬────────────────────┤
│ 280px    │  主内容 max 1120px               │ 260px              │
│ 章节导航  │                                  │ 本节大纲 + 资源     │
│ （压缩版 │  ┌──────────────────────────┐    │                    │
│  lesson  │  │      16:9 播放器          │    │ 本节大纲            │
│  行，40px│  │   （无装饰边框，radius 10）│    │  · 建项目           │
│  行高）  │  └──────────────────────────┘    │  · 第一条指令       │
│          │                                  │  · 部署             │

### 关键节点时间轴（本项目最重要的自定义部件）

数据来自录制时产出的 `lesson-XX.chapters.json`（见 DESIGN.md 附录 A.8）。

- 每条一行，48px 高，`divide-y --border-soft`
- 左：mono 13px 时间码 `--accent`（可点，seek 到该秒）
- 中：18px Lucide 图标，按 `type` 取 —— `step → circle-dot`(`--muted`) / `prompt → message-square-code`(`--track-video`) / `pitfall → triangle-alert`(`--warn`)
- 右：中文步骤名 16px `--fg-2`
- 当前播放位置所在行：`background: var(--accent-wash)`，随播放实时移动（`--motion-slow` 过渡）
- **这同时是图文正文的锚点导航**：点击时间码 seek 视频，点击步骤名滚动到正文对应小节

### 三类嵌入块

1. **代码块** — `--surface-warm` 底 + 1px `--border`，顶栏 36px（文件名 mono 13px `--meta` + 语言 + `copy` 按钮）。行号 `--meta` / tabular-nums / `user-select:none`。
   **高亮行 = 整行 `--accent-wash` 底 + 该行行号变 `--accent`，不用左侧彩色边框**（规避侧条纹反模式）。
2. **提示词块** — 头部 `message-square-code` 20px `--accent` + 「给 AI 的指令」，内容 mono 14px 可换行，变量占位 `[方括号]` 着 `--accent`，右上 `copy`。底 `--surface-warm` + 1px `--border`。
3. **踩坑块** — 底 `color-mix(warn 8%, surface)`，边框 `color-mix(warn 25%, transparent)`，头部 `triangle-alert` 20px `--warn` + 「这里会卡住」。**正文用 `--fg-2` 不用 warn 色**，避免整块刺眼。

### 底部导航

上一节 / 下一节 双栏（各占 50%，显示节标题，`arrow-left` / `arrow-right`）。
`标记完成` Primary 按钮；已完成后变 Ghost + `circle-check` + 文案「已完成」，**不弹撒花动画**（MOTION_INTENSITY 3）。

### 五态

| 态 | 表现 |
|---|---|
| Loading | 播放器区 `aspect-ratio:16/9` 骨架（防 CLS），时间轴 4 行 skeleton，正文 6 行文字骨架 |
| Empty | 本节暂无图文版时：`file-text` 32px `--meta` + 「这节是纯实操，图文版整理中」+ 预计时间。**不显示空白区** |
| Error | 视频加载失败 → 播放器区内联 `triangle-alert` + 「视频加载失败」+ `重试` + 「或先看图文版 ↓」（给替代路径，不是死胡同） |
| Populated | 如上 |
| Edge | 无 chapters.json → 时间轴整块隐藏，正文上移；超长代码块 → 高度上限 480px + 内部滚动 + 底部渐隐提示可展开 |

### 移动端（<768px）

- 播放器 sticky 顶部；正文滚动 >200px 时收为**右下角 mini player**（宽 40vw、16:9、radius 10px、1px `--border-soft`、可拖动、右上 `x` 关闭）
- 章节导航 → 底部抽屉（`menu` 触发，抽屉高度 70vh，含搜索框）
- 右栏资源 → 折叠进正文顶部的一行横向滚动 chip
- 时间轴保留（这是移动端最有价值的部件），行高升至 56px
- 底部固定条 48px：`上一节` / `标记完成` / `下一节`，触摸目标 ≥44px

### 无障碍要点

- 视频必带 `.vtt` 字幕轨；**图文版本身就是视频的无障碍替代文本**（这是本课设计的天然优势，要在 a11y 说明中写明）
- 时间轴每行是 `<button>`，`aria-label="跳转到 2 分 14 秒：初始化 Next.js 项目"`
- 播放器支持空格播放/暂停、← → 前后 5 秒、`J/K/L`（对齐专业播放器肌肉记忆）
- `prefers-reduced-motion` → mini player 收起不做位移动画，直接切换；时间轴当前行高亮不做过渡

## 四、跨页面一致性契约

1. **章节列表页的 lesson 行** 与 **播放页左栏导航行** 与 **Landing 大纲预览行** 是**同一个组件**的三种密度变体（56 / 40 / 56px），共用同一套状态图标与类型 pill。学员在三处看到同一种行 → 建立熟悉感（Product 寄存器标杆）。
2. **录屏视频里的 IDE 配色** 与 **网页代码块配色** 同源（GitHub Dark Default 派生），学员从视频切到图文不跳色。
3. **`lesson-XX.chapters.json`** 是视频与图文的唯一连接点，录制流程必须产出它，否则播放页时间轴降级隐藏。
