### 本轮我自己犯的两个错（必须记，否则下轮照犯）

1. **静默假数据**：4 个 URL 的抓取循环里 curl 因 TLS 失败，我却继续解析**上一次留下的临时文件**，得出「4 个不同页面返回同一篇博客」的假结论。发现方式：单页复核 `X-Matched-Path` 与 title 不符。
   → 纪律：**curl 必须断言 HTTP 码并写唯一文件**；解析前先校验文件 mtime。
   根因补充：Git Bash 的 `/tmp` 与 Windows Python 的 `/tmp` **不是同一个目录**（前者在 `%LOCALAPPDATA%\Temp`，后者在 `C:\tmp`），跨工具传文件一律用仓库内相对路径。
2. **管道吞退出码**：`node ... | tail` 后 `$?` 取到的是 `tail` 的退出码，把 exit 3 记成了 0。发现方式：与 A1 的采集方式对比不一致。
   → 纪律：要判退出码时先重定向到文件再读，不接管道。
3. **目标对象认错**：把 "The Tool Directory" 当成 `thefreetoolsdirectory.com`，差点用「已提交过」为由不提交。
   发现方式：回查 Notion 90 天计划 B4 段原文，正确站点是 `thetooldirectory.com`。
   → 纪律：**凡「已做过」的判断，先回查原始记录里的 URL**，不靠名字相似度。
