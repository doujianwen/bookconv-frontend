### 唯一真实生产链路

```
push main → Vercel GitHub Integration → vercel[bot] 创建 GitHub Deployment (Production)
          → Vercel 构建 → deployment status=success → bookconv.com
```

### 触发与覆盖规则（实测）

- 一次 push 事件 = 恰一个 Production 部署（部署头 SHA）；批量 push 的非头 SHA 零部署（11-10 以来 16 push / 10 deployment，逐一时间戳对齐，误差 ≤2 分钟）。
- GHA 通道从未贡献部署；若其 token 被修复，同一 push 将产生**第二个** Production 部署（REST 直建 + 集成自动建）→ 重复部署风险当前不存在、修复方案 A 会引入。
