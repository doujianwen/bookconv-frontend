## 2. 唯一内容修正（定稿版替换原 Checklist 第 5 条）

原：
> 5. Watch the file size. Free online converters usually cap uploads at a few megabytes; image-heavy books may need a desktop tool.

定稿：
> 5. Watch the file size. BookConv's single-file converter accepts files up to 100 MB with no sign-up — large scanned or image-heavy books work there. (Batch mode stays at 4 MB per file.)

理由：①与产品真实能力一致（不编造、不贬低自家 100MB 能力）；②batch 4MB 表述与 batch 页 FAQ 一致；③这是竞品页普遍缺失的真实差异点。其余全文以底稿为准。
