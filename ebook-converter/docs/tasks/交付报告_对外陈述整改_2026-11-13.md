- **UNKNOWN 三态**：核心文件缺失 / 读取失败 / JSON 非法 → `exit 2`（JSON 非法为 `exit 1`），绝不降级为 PASS。
- **显式缺口**：`KNOWN_EXCLUSIONS` 打印 P0 证言缺口与 P1 长尾缺口，防止「核心 0 命中」被误读成全站干净。
