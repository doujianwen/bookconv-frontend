## 发布纪律（防 Google 惩罚）

| 规则 | 说明 |
|---|---|
| 速率控制 | 每周最多 1-2 篇新博客，不批量发布 |
| 质量优先 | 每篇 ≥ 1500 词，含实用表格/步骤/FAQ |
| 内链闭环 | 新博客必须链接到 2+ 现有高引用博客 |
| 间隔发布 | 相邻 IP 博客间隔 ≥ 3 天 |
| 增量验证 | 每篇发布后观察 3-5 天 Bing AI 引用变化再发下一篇 |

## 风险控制

1. **不批量创建**：每次只生成 1 篇，发布后观察 3-5 天再决策下一篇
2. **不重复内容**：每篇 IP 博客聚焦不同查询角度，避免 google 判定为 thin content
3. **不刷 IP**：优先选择公共领域或高知名度 IP，规避版权风险
4. **监控指标**：每篇发布后跟踪 Bing AI 引用数变化，低于预期则调整策略
