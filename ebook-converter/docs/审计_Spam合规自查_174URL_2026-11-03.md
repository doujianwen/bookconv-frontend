## 1. 方法论与可复现性

1. `curl` 经本机代理抓取线上 `sitemap.xml`（30,257 字节，174 个 `<loc>`）。
2. 并发 12 抓取每个 URL 原始 HTML，落盘缓存 `数据分析/seo-audit/html/<idx>.html`（可断点续跑，未重复抓取）。
3. 每页提取：HTTP 状态、标题、H1、正文词数、独立词数（≥3 字符 token）、内部/外部链接数、affiliate 模式、canonical、hreflang、robots。
4. 近重复：每页生成 5-gram 词袋 shingle 集合，同板块（type）两两计算 Jaccard；≥0.70 判为同簇。
5. Cloaking：4 个样本分别用普通 UA 与 `Googlebot/2.1` UA 抓取，比对词数。
6. 分类规则（优先级）：冻结名单 → 外链价值（≥3 外链或 affiliate）→ formats（规模化薄页）→ 法务/工具页豁免 → 薄内容(词<250 且 独立<180) → 部分重叠观察 → 保留。

**不可确证项不掩饰**：本审计未逐页验证「是否被 Bing AI 引用」——这是站长侧数据（见 §6 约束）。近重复阈值 0.70 为经验值，仅作簇划分，不影响「无门页」结论（所有板块最大相似度均 <0.40）。

## 2. 四维度逐项核查

### 2.1 Scaled content abuse
- **命中板块：`/formats/*`（15 页）**。平均 180 词、最小 159 词、最大 210 词；独立词 96–127。内容为模板化「格式是什么 / 能否转换」短桩，增量价值低，符合 Google 8 月更新重点打击的「大规模生成、低价值页」特征。
- **未命中板块**：convert（均 2,480）、guide（1,856）、blog（1,566）、es（1,865）均为长文，且有各自专有内容（步骤、截图说明、格式对比），非规模化薄页。
- **结论**：存在规模化薄内容风险，但**范围小且明确**（仅 15 个格式页），非全站性问题。

### 2.2 Doorway pages
- 同板块内最大 Jaccard 相似度：**blog 0.361、es 0.361、guide 0.276、convert 0.256、formats 0.274、data 0.153**。全部远低于 0.70。
- 最高相似对举例：convert 内 `azw3-to-mobi ↔ mobi-to-azw3` 仅 25.6%；`/formats/lit ↔ /formats/doc` 27.4%。属「同主题不同格式」的正常内容重叠，非门页。
- **结论：0 个门页 / 0 个近重复簇。**

### 2.3 Thin affiliate
- 全 174 页外链扫描：匹配 affiliate 模式（amzn.to / amazon /dp/ / shareasale / clickbank / impact / rakuten / awin / `?ref=` / `tag=`）的外部链接 = **0 个联盟链接**。
- 唯一 Amazon 提及：`/convert/epub-to-mobi` 正文引用 `amazon.com/Amazon-Kindle/dp/B08KTZ8249`（Kindle 产品页），**无 `?tag=` 附属参数**，属良性产品说明，非联盟营销。
- **结论：无 thin affiliate 风险。**

### 2.4 Cloaking
- 样本（首页 / convert / blog / formats）普通 UA 与 Googlebot UA 返回词数 **完全一致（delta=0）**。站点为 Next.js SSR，无基于 UA 的内容分支（与代码层一致）。
- **结论：未检出 cloaking。**
