## 1. Pre-Writing Checklist

Before writing any blog post, confirm ALL of the following:

```
[ ] Primary keyword identified and validated
[ ] Secondary keywords / LSI keywords identified
[ ] Search intent confirmed (informational / commercial / transactional)
[ ] Competitor analysis completed (top 3 ranking pages reviewed)
[ ] Target word count determined (based on competitor analysis)
[ ] Article angle / unique value proposition defined
[ ] Internal linking opportunity identified (link FROM and TO which pages)
[ ] Author credentials ready (for E-E-A-T)
[ ] Source/citation links prepared (at least 3 authoritative external links)
[ ] Featured snippet / PAA targets identified
[ ] GEO format requirements noted (Key Takeaways, Q&A sections)
```

## 2. Keyword Research Standards

### 2.1 Primary Keyword Selection

| Criterion | Minimum Standard |
|-----------|-----------------|
| Search Volume | >100 searches/month (US) |
| Keyword Difficulty (KD) | <60 (new sites: <40) |
| Intent | Single clear intent (avoid mixed intent) |
| Commercial Value | Matches business goals |
| Content Fit | Can naturally serve the searcher's need |

### 2.2 Keyword Placement Rules

```
┌─────────────────────────────────────────────────────┐
│  ELEMENT          │  REQUIREMENT                    │
│                   │                                  │
│  URL slug         │  Primary keyword, hyphenated    │
│  H1 Title         │  Primary keyword, front-loaded  │
│  First 100 words  │  Primary keyword mentioned once  │
│  H2/H3 Headings   │  Secondary keywords naturally    │
│  Meta Title       │  Primary keyword + brand (50-60) │
│  Meta Description │  Primary + secondary (150-160)   │
│  Image ALT        │  Keyword-rich, descriptive       │
│  Conclusion       │  Repeat primary keyword once      │
└─────────────────────────────────────────────────────┘
```

### 2.3 LSI & Semantic Keywords

Include 5–10 semantically related terms naturally throughout the article:

**Example for "best protein powder for muscle gain":**
- whey isolate / concentrate
- amino acid profile
- post-workout recovery
- lean muscle
- protein intake
- supplement stack
- bioavailability
- third-party tested

### 2.4 Competitor Analysis (Minimum 3 Pages)

For each top-ranking competitor page, note:
- Word count
- Heading structure (H2/H3 hierarchy)
- Content depth on each subtopic
- Unique data points or statistics they cite
- Media usage (images, videos, infographics)
- Schema types used
- Internal/external links

## 3. SEO On-Page Writing Rules

### 3.1 Title Tag (Meta Title)

```
✅ CORRECT:
"Best Protein Powder for Muscle Gain in 2026 | Expert Review"
[Primary keyword front-loaded | Year | Differentiation | Brand]

❌ WRONG:
"Protein Powder - Muscle Gain - Best Products - Reviews"
[Keyword stuffed | No value proposition | Confusing]
```

**Rules:**
- Length: 50–60 characters
- Front-load primary keyword
- Include year for recency (if relevant)
- Add power words: Best, Complete, Ultimate, Expert, Proven
- Include brand name at the end (after |)

### 3.2 Meta Description

```
✅ CORRECT:
"Looking for the best protein powder for muscle gain? Our experts reviewed 
the top 12 brands based on taste, purity, and value. See which protein 
powders actually work in 2026."
[Hook | What the article covers | Specificity | CTA | Year]

❌ WRONG:
"Best protein powder for muscle gain. We review the best protein powders."
[Duplicate of title | No hook | No specifics | Weak]
```

**Rules:**
- Length: 150–160 characters
- Include primary + secondary keyword
- Use active voice and action verbs
- Add a subtle call-to-action
- Match the user's expectation from the SERP

### 3.3 URL Structure

```
✅ CORRECT:  /best-protein-powder-for-muscle-gain
❌ WRONG:    /protein-powder-muscle-gain-2026-review-guide
❌ WRONG:    /p/12345
```

**Rules:**
- Keep it short (3–5 words preferred)
- Include primary keyword
- Use hyphens, not underscores
- No stop words (the, a, and, for)
- Lowercase only

### 3.4 Heading Hierarchy

```
✅ CORRECT:
H1: Best Protein Powder for Muscle Gain (only ONE H1)
  H2: What to Look for in a Protein Powder
    H3: Protein Source (Whey vs Casein vs Plant)
    H3: Amino Acid Profile
    H3: Third-Party Testing & Certifications
  H2: Top 12 Protein Powders for Muscle Gain (2026)
  H2: How to Choose the Right Protein Powder
  H2: FAQ
```

**Rules:**
- ONE H1 per article (matches the title)
- Logical hierarchy: H1 → H2 → H3
- Include keywords in H2s (not all H3s)
- Don't skip heading levels
- Make headings descriptive, not generic

## 4. Content Structure Standards

### 4.1 Article Length Guidelines

| Content Type | Target Word Count | Rationale |
|-------------|-------------------|-----------|
| How-to Guide | 1,500–2,500 | Step-by-step needs depth |
| Listicle | 1,200–2,000 | Each list item explained |
| Comparison | 2,000–3,500 | Side-by-side analysis |
| Ultimate Guide | 3,000–6,000 | Comprehensive coverage |
| Opinion/Thought Leadership | 800–1,500 | Concise and impactful |
| Case Study | 2,000–4,000 | Data + narrative |

> **Rule:** Always match or exceed the word count of the top-ranking competitor. If the top 3 pages average 2,000 words, aim for 2,200–2,500 words minimum.

### 4.2 Article Outline Template

```
# [Primary Keyword] | [Hook/Value Prop]

## Introduction (150–200 words)
  - Pain point / hook sentence
  - What this article covers (3–5 bullet roadmap)
  - Credibility sentence ("After reviewing 50+ products...")
  - Primary keyword in first 100 words

## Main Body
  ### H2 Section 1
    Content with H3 subsections as needed
    Include data, examples, expert quotes
    Internal link to [relevant page]
    
  ### H2 Section 2
    ...
    
  ### H2 Section 3
    ...

## [H2] Key Takeaways (for GEO)
  - 3–5 bullet points summarizing key findings
  - Make these quotable and extractable

## [H2] FAQ (Schema-ready)
  - 5–7 questions from PAA / "People Also Ask"
  - Concise answers (50–100 words each)
  - Question in H3, answer in paragraph below
  
## Conclusion (150–200 words)
  - Restate primary keyword
  - Summarize key takeaways
  - Call to action (download, comment, share)
```

### 4.3 Content Quality Rules

```
✅ DO:
  - Answer the query in the first 100 words
  - Write in active voice (80%+ of sentences)
  - Use short paragraphs (2–4 sentences max)
  - Include at least 1 data point or statistic per H2 section
  - Cite authoritative sources (gov, edu, established media)
  - Add 2–3 expert quotes or original insights
  - Include real examples and use cases
  - Make claims specific ("72% of users" > "Most users")

❌ DON'T:
  - Write fluff or filler sentences
  - Use passive voice excessively
  - Include opinions without evidence
  - Repeat the same information in different sections
  - Use generic phrases ("in today's world", "it's important to note")
  - Write clickbait headings that don't match content
```

### 4.4 Internal & External Linking

**Internal Links:**
- Add 2–4 internal links per 1,000 words
- Use descriptive anchor text (never "click here")
- Link to relevant pillar pages or supporting content
- Link contextually within body paragraphs, not isolated sentences

```
✅ CORRECT: "For a complete guide to macronutrients, see our [Macronutrients 101 guide]."
❌ WRONG:       "For more information, [click here]."

✅ CORRECT: "Our [2026 SEO Audit Checklist] covers the complete technical review process."
❌ WRONG:       "[This checklist] covers technical review."
```

**External Links:**
- Link to 3–5 authoritative external sources per article
- External links to .gov, .edu, or established media outlets preferred
- Link to niche-specific authoritative blogs (DA 50+)
- Open in new tab (target="_blank")

## 5. E-E-A-T Requirements

> **E-E-A-T = Experience · Expertise · Authoritativeness · Trustworthiness**
> Critical for YMYL topics. Apply to all content regardless.

### 5.1 Experience Signals

```
[ ] Author has first-hand experience with the topic
[ ] Real product testing results mentioned
[ ] Real examples, case studies, or personal anecdotes included
[ ] "We tested..." / "Our results showed..." language used
[ ] Date of testing or data collection specified
```

### 5.2 Expertise Signals

```
[ ] Author bio with relevant credentials displayed
[ ] Author photo visible on the page
[ ] Clear author name attached to the article
[ ] Educational background or industry experience mentioned
[ ] Certifications or qualifications cited
[ ] Professional associations mentioned
```

### 5.3 Author Bio Box Template

```
**About the Author:**
[Name] is a [Certification] with [X years] of experience in [Field]. 
Previously worked at [Notable Org]. Has been featured in [Media Names]. 
Currently [Current Role]. [Link to full bio page]

*[Certification] · [Second Credential] · [LinkedIn Profile]*
```

### 5.4 Trustworthiness Signals

```
[ ] Article last updated date displayed
[ ] Data sources and citations clearly listed
[ ] Clear publication date
[ ] Contact information or author page accessible
[ ] Privacy policy and terms page linked
[ ] HTTPS enabled (site-wide)
[ ] Error-free, accurate content (factual cross-check)
```

## 6. Technical SEO Checklist

### 6.1 Image Optimization

```
[ ] All images use descriptive, keyword-rich alt text
[ ] Images compressed (WebP format preferred, <150KB)
[ ] Responsive image sizes (srcset implemented)
[ ] Lazy loading implemented (loading="lazy")
[ ] Image filenames are descriptive (not IMG_1234.jpg)
[ ] At least one image includes the primary keyword in alt text
[ ] Featured/hero image has descriptive alt text
```

**Alt Text Rules:**
```
✅ CORRECT: "Close-up of whey protein powder scoop in a blue shaker bottle"
❌ WRONG:     "protein powder"
❌ WRONG:     "image of protein supplement on kitchen counter photo"
```

### 6.2 Page Speed (Core Web Vitals)

| Metric | Target | Common Fixes |
|--------|--------|--------------|
| LCP (Largest Contentful Paint) | < 2.5s | Optimize images, CDN, server |
| INP (Interaction to Next Paint) | < 200ms | Reduce JS blocking |
| CLS (Cumulative Layout Shift) | < 0.1 | Define image dimensions |

### 6.3 Mobile Optimization

```
[ ] Responsive design (mobile-first)
[ ] Font size minimum 16px for body text
[ ] Touch targets minimum 48x48px
[ ] No horizontal scrolling
[ ] Content parity with desktop
[ ] Viewport meta tag present
```

### 6.4 Readability Standards

```
Target Grade Level: 8th Grade (US) — Flesch-Kincaid
Sentence Length:    Average 15–20 words
Paragraph Length:   2–4 sentences maximum
Line Spacing:       1.5–1.7 for comfortable reading
Font:               Sans-serif (system fonts or Google Fonts)
Font Size:          16–18px for body text
```

## 7. GEO Optimization Rules

> **GEO = Generative Engine Optimization**
> Making your content visible and quotable by AI engines (ChatGPT, Gemini, Perplexity, Claude, etc.)

### 7.1 Key Takeaways Box (MANDATORY)

Place this near the top or end of every article. Format as a distinct block:

```
┌─────────────────────────────────────────────────────────────┐
│  🔑 KEY TAKEAWAYS                                            │
│                                                              │
│  • [Specific finding #1 with data or conclusion]             │
│  • [Specific finding #2 with data or conclusion]             │
│  • [Specific finding #3 with data or conclusion]            │
│  • [Actionable recommendation #1]                             │
│  • [Actionable recommendation #2]                            │
└─────────────────────────────────────────────────────────────┘
```

**Rules:**
- Use 3–6 bullet points
- Start with the most important finding
- Include specific numbers, percentages, or rankings
- Avoid vague summaries
- Each point should be independently meaningful
- Bold the key phrase in each bullet

### 7.2 Q&A Section (MANDATORY)

Transform content into PAA-style Q&A format:

```
### H2: Frequently Asked Questions

#### Q1: [Direct question from PAA / common query]
[A direct, concise answer. 50–100 words. Answer the question in the first sentence.]

#### Q2: [Another common question]
[Direct answer with one supporting detail or data point.]
```

**Rules:**
- 5–7 questions minimum
- Match exact phrasing of PAA questions (verify in Google)
- Answer directly and immediately
- Include one specific data point or example per answer
- Don't be vague — AI engines extract direct answers

### 7.3 Quotability Standards

AI engines extract and cite content. Make content quotable:

```
✅ QUOTABLE:
"Third-party testing found that whey isolate protein has a bioavailability 
of 90–95%, compared to 70–80% for whey concentrate."

❌ NOT QUOTABLE:
"Protein powder is a popular supplement choice for people who work out."

✅ QUOTABLE:
"The recommended daily protein intake for muscle gain is 1.6–2.2g per 
kilogram of body weight, according to a 2018 meta-analysis in the 
British Journal of Sports Medicine."

❌ NOT QUOTABLE:
"You should eat enough protein to build muscle."
```

**Quotability Checklist:**
```
[ ] Use specific numbers, dates, percentages
[ ] Attribute claims to named studies, organizations, or experts
[ ] State exact thresholds ("more than 50%" not "a lot of")
[ ] Use definitive language ("is" not "may be" for established facts)
[ ] Avoid hedging on factual data
[ ] Quote experts with full attribution
[ ] Include study names, journal names, publication years
```

### 7.4 Entity Optimization

AI engines understand entities (people, places, organizations, products).

```
✅ STRONG ENTITIES:
- Named products (e.g., "Optimum Nutrition Gold Standard Whey")
- Named studies (e.g., "Morton et al., 2018")
- Named organizations (e.g., "ISSN", "FDA", "WHO")
- Named locations (e.g., "Northeast Asia", "Silicon Valley")
- Named tools/platforms (e.g., "Google Search Console", "Ahrefs")

❌ WEAK ENTITIES:
- Generic "supplements" without brand names
- Vague "research shows" without citation
- Anonymous "experts say"
```

### 7.5 AI Crawler Access

```
[ ] robots.txt allows AI bots (GPTBot, Claude, Gemini)
[ ] Structured data (Schema.org) present
[ ] No blocking of OpenAI/Anthropic crawler IPs
[ ] Content is not gated behind login or paywall
[ ] Content accessible via direct URL crawl
[ ] Canonical URLs properly set
[ ] Sitemap includes all published articles
```

## 8. Schema Markup Standards

### 8.1 Required Schema Types by Article Type

| Article Type | Required Schemas |
|-------------|-----------------|
| Blog Post | Article, Author, Organization |
| How-to Guide | HowTo, Article |
| FAQ Page | FAQPage |
| Product Review | Article, Product (aggregate), Review |
| Comparison | Article, Product, FAQPage |
| News/Breaking | Article (NewsArticle), BreadcrumbList |

### 8.2 Article Schema Template

```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[Exact H1 Title - max 110 chars]",
  "description": "[Meta description]",
  "image": "[Featured image URL]",
  "author": {
    "@type": "Person",
    "name": "[Author Full Name]",
    "url": "[Author bio page URL]",
    "jobTitle": "[Job Title]",
    "worksFor": {
      "@type": "Organization",
      "name": "[Company Name]"
    }
  },
  "publisher": {
    "@type": "Organization",
    "name": "[Site Name]",
    "logo": {
      "@type": "ImageObject",
      "url": "[Logo URL]"
    }
  },
  "datePublished": "[YYYY-MM-DD]",
  "dateModified": "[YYYY-MM-DD]",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "[Canonical URL]"
  }
}
```

## 9. De-AI-ification Process

> **MUST RUN before final publication.** AI-generated content has detectable patterns. Apply these techniques to make content sound human-written.

### 9.1 Readability De-AI-ification

```
❌ AI TELL: "In today's digital landscape, it's crucial to understand..."
✅ HUMAN:   "Google's latest update changed how we approach content strategy."

❌ AI TELL: "Furthermore, it is important to note that..."
✅ HUMAN:   "But here's what most people miss:"

❌ AI TELL: "In conclusion, it can be said that..."
✅ HUMAN:   "Here's the bottom line:"

❌ AI TELL: "The aforementioned data suggests..."
✅ HUMAN:   "This data points to one clear conclusion:"

❌ AI TELL: "Additionally, it's worth mentioning that..."
✅ HUMAN:   "There's another factor worth considering:"
```

### 9.2 Sentence Structure De-AI-ification

```
AI PATTERN: "Here are the key benefits of X:
  - It helps improve Y
  - It is cost-effective
  - It is easy to use"

HUMAN PATTERN: "The main appeal of X is [benefit 1]. 
But what really sets it apart is [benefit 2]. 
And unlike most alternatives, [benefit 3]."

→ Replace bullet lists with flowing paragraphs where possible
→ Vary sentence length (mix 8-word and 25-word sentences)
→ Use contractions (don't → don't, cannot → can't)
→ Use colloquialisms sparingly but naturally
→ Add rhetorical questions occasionally
```

### 9.3 Paragraph De-AI-ification

```
AI PATTERN: Every paragraph is exactly 3-4 sentences with similar length.

HUMAN PATTERN: 
- Paragraph 1: 2 sentences (short, punchy)
- Paragraph 2: 5 sentences (builds momentum)  
- Paragraph 3: 1 sentence (punchline)

→ Vary paragraph lengths intentionally
→ Use one-sentence paragraphs for emphasis
→ Mix "Firstly, Secondly, Finally" with "But also...", "And then there's..."
→ Use em dashes (—) for asides and emphasis
→ Use semicolons occasionally
```

### 9.4 Vocabulary De-AI-ification

Remove these AI vocabulary patterns:

```
AVOID (replace with alternatives):
─────────────────────────────────────────────────────────
"leverage"           → use, take advantage of, harness
"utilize"            → use, apply
"delve into"         → explore, dig into, look at
"landscape"          → field, world, market, space
"realm"              → area, field, world
"facilitate"         → help, enable, make it easier
"robust"             → strong, solid, reliable
"comprehensive"      → thorough, complete, detailed
"cutting-edge"       → latest, newest, advanced
"game-changer"       → significant, major shift, important development
"navigate"           → deal with, handle, manage, work through
"in today's world"   → (delete entirely)
"it is important to note" → (delete entirely)
"needless to say"    → (delete entirely)
"as a matter of fact" → (delete entirely)
"it goes without saying" → (delete entirely)
"with that being said" → but, however, that said
─────────────────────────────────────────────────────────
```

## 10. Post-Publication Checklist

### Before Publishing:

```
[ ] All keyword placements verified
[ ] No duplicate content issues
[ ] All external links checked and working
[ ] Internal links placed and correct
[ ] Featured image optimized (compressed, alt text set)
[ ] Schema markup validated (use https://validator.schema.org)
[ ] Meta title = 50–60 characters
[ ] Meta description = 150–160 characters
[ ] H1 matches meta title
[ ] URL slug is clean and short
[ ] Author bio attached
[ ] Article date set (datePublished)
```

### Immediately After Publishing:

```
[ ] Submit URL to Google Search Console (Inspect URL → Request Indexing)
[ ] Verify sitemap includes new URL
[ ] Check Google SERP preview (title/description rendering correctly)
[ ] Verify on mobile (appearance check)
[ ] Set up internal link from existing relevant article
[ ] Schedule social share if applicable
```

### 1 Week After Publishing:

```
[ ] Check indexing status in Google Search Console
[ ] Monitor for any crawl errors
[ ] Check if any structured data errors in GSC
[ ] Verify featured image is indexing properly
```

## 11. Writing Workflow Summary

```
PHASE 1: RESEARCH (Before Writing)
──────────────────────────────────────
 Step 1  │ Keyword research & validation
 Step 2  │ Competitor analysis (top 3 pages)
 Step 3  │ Identify search intent
 Step 4  │ Find PAA questions & featured snippet targets
 Step 5  │ Gather 3+ authoritative sources/citations
 Step 6  │ Identify internal link opportunities

PHASE 2: OUTLINE (Before Writing)
──────────────────────────────────────
 Step 7  │ Define unique angle / value proposition
 Step 8  │ Build article outline (H2/H3 structure)
 Step 9  │ Plan Key Takeaways points (for GEO)
 Step 10 │ Plan 5–7 FAQ questions (for GEO + Schema)
 Step 11 │ Define target word count

PHASE 3: WRITING (First Draft)
──────────────────────────────────────
 Step 12 │ Write introduction (hook + roadmap)
 Step 13 │ Write main body (H2 sections)
 Step 14 │ Write Key Takeaways box (GEO)
 Step 15 │ Write FAQ section (GEO + Schema)
 Step 16 │ Write conclusion (summary + CTA)
 Step 17 │ Add internal links within content
 Step 18 │ Add external links to authoritative sources
 Step 19 │ Add author bio section

PHASE 4: SEO OPTIMIZATION (Second Pass)
──────────────────────────────────────
 Step 20 │ Insert primary keyword in first 100 words
 Step 21 │ Optimize all H2/H3 headings
 Step 22 │ Add LSI/semantic keywords naturally
 Step 23 │ Optimize all image alt texts
 Step 24 │ Verify meta title (50–60 chars)
 Step 25 │ Write meta description (150–160 chars)
 Step 26 │ Set clean URL slug
 Step 27 │ Add FAQ schema markup (JSON-LD)
 Step 28 │ Add Article schema markup (JSON-LD)

PHASE 5: DE-AI-IFICATION (Third Pass)
──────────────────────────────────────
 Step 29 │ Remove AI vocabulary patterns
 Step 30 │ Vary sentence and paragraph lengths
 Step 31 │ Replace bullet lists with flowing prose where possible
 Step 32 │ Add contractions and colloquial touches
 Step 33 │ Read aloud — fix anything that sounds robotic

PHASE 6: FINAL REVIEW
──────────────────────────────────────
 Step 34 │ Full technical SEO checklist
 Step 35 │ Full E-E-A-T checklist
 Step 36 │ Full GEO checklist
 Step 37 │ Schema markup validation (validator.schema.org)
 Step 38 │ Read final draft for coherence and flow
 Step 39 │ Pass to human for review and approval

PHASE 7: PUBLICATION & MONITORING
──────────────────────────────────────
 Step 40 │ Publish article
 Step 41 │ Submit to Google Search Console
 Step 42 │ Set up internal links from related articles
 Step 43 │ Monitor indexing (1 week)
 Step 44 │ Track rankings (2–4 weeks)
 Step 45 │ Monitor GSC for errors
```
