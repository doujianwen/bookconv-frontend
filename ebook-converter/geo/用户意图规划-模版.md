# 用户意图规划-模版

提示词：这个是我的网站bookconv.com关键词规划，帮我列出用户可能在gemini中提问的问题。
基于这份 **27 个电子书转换关键词列表**，用户在 Google Search (AI Overviews) 或 Gemini 对话框中提问时，绝不会像在 Traditional Search 中那样只输入短词（如 `epub to mobi`），而是倾向于使用**完整句式、带有具体场景、硬件设备、报错解决或批量需求**的自然语言。

将这 27 个关键词按照用户使用 Gemini 时的**核心真实意图**，拆解为以下 6 大类可能在 Gemini 中提问的自然语言问题：

## 1. 设备与阅读器适配类（Kindle / Kobo / Linux 等）

用户通常不知道某种格式的具体名称，或者清楚自己的设备，直接向 Gemini 寻求针对设备的最佳转换方案。

* **EPUB / AZW3 / MOBI (Kindle 痛点)**:
  * _"How do I convert an EPUB file so I can read it on my Kindle Paperwhite without losing formatting?"_
  * _"Amazon stopped supporting MOBI on Kindle, should I convert my books to EPUB or AZW3 now?"_
  * _"What is the best format for Kindle, AZW3 or MOBI? How to convert AZW3 to MOBI?"_
* **Linux 终端 / 系统特定**:
  * _"How can I convert EPUB to PDF on Linux command line using a simple tool?"_
* **漫画 / 图像阅读器 (CBR / CBZ / PNG)**:
  * _"How to convert CBR comic files to PDF so I can read them on my iPad mini?"_
  * _"Can I convert EPUB pages into PNG or JPG images to view them in a gallery?"_

## 2. AI 喂料与文本提取类（NotebookLM / LLM / RAG 场景）

在 AI 工具爆发的当下（如 SERP 中出现 Reddit r/notebooklm），很多用户寻找格式转换是为了把电子书作为知识库输入给 Gemini、NotebookLM 或 ChatGPT。

* **TXT / Word 纯文本提取**:
  * _"How do I extract raw text from an EPUB or MOBI book so I can upload it into NotebookLM?"_
  * _"What is the easiest way to convert MOBI to TXT or EPUB to TXT without line break issues?"_
  * _"How to turn an EPUB ebook into a Word document (DOCX) so I can edit and summarize it?"_
* **HTML / 网页结构化**:
  * _"How to convert EPUB to clean HTML so I can parse the text for a data project?"_
  * _"I have a set of HTML files/webpages, how do I compile them into a single EPUB file?"_

## 3. 旧版遗留格式与冷门格式转换类（LIT / FB2 / DJVU / RTF）

用户手头有很旧的书籍格式，现代软件无法直接打开，向 Gemini 询问拯救这些旧电子书的方法。

* **LIT / FB2 / DJVU 解决办法**:
  * _"I found some old Microsoft Reader (.lit) books from 2005, how can I convert LIT to EPUB to read them today?"_
  * _"How to convert DJVU scanned research papers to PDF with good resolution?"_
  * _"What is an FB2 file, and how do I convert FB2 to EPUB for my e-reader?"_
* **RTF / DOC 老旧文稿**:
  * _"How to convert RTF documents into EPUB for publishing?"_

## 4. 打印、排版与固定版面需求类（PDF \<-> EPUB / Word）

这类用户关注的是“版面保持”、“方便打印”或者“可编辑性”。

* **PDF 与可流动文本转换**:
  * _"How to convert a scanned PDF into an EPUB file so the text reflows nicely on a phone screen?"_
  * _"How do I convert an EPUB file into a PDF so I can print out a physical copy?"_
  * _"Is it possible to convert DOCX or Word documents straight to EPUB without messing up the table of contents?"_

## 5. 效率与批量转换需求（免费 / 免下载 / Calibre 替代方案）

用户不想下载像 Calibre 那样笨重的桌面软件，希望 Gemini 推荐轻量级、在线且无副作用的工具。

* **轻量级 & 免安装需求**:
  * _"What is the fastest online tool to convert EPUB to MOBI for free without installing Calibre?"_
  * _"Are there any safe online web converters for AZW3 to PDF that don't steal my files?"_
  * _"Is there a simple web app to turn TXT files into EPUB books for mobile reading?"_

## 6. 报错、格式对比与概念排查类

用户在阅读或转换时遇到报错，直接粘贴错误提示或向 Gemini 询问概念差异。

* **格式区别与排错**:
  * _"What is the difference between EPUB and AZW3, and which one preserves fonts better?"_
  * _"Why does my converted PDF look broken when I change it from EPUB to PDF?"_
  * _"How do I convert DJVU to PDF without losing page orientation?"_
