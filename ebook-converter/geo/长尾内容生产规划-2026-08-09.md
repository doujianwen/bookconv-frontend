## 4. 执行纪律（每次新建必须遵守）

1. 写数据 → `index.ts` 注册 → `public/llms.txt` 同步（条数须等于 `getAllXxx()`）→ `scripts/seo-critic.mjs` 校验（退出码 1 = 门禁失败）。
2. 新 `/convert/*` 页：**先用 `conversion-verifier` / 实测转换确认能转**，再建（防软 404）。
3. 内链一律走 `src/lib/internal-links.ts` helper，不手写 URL；保证博客↔指南↔转换三角闭环。
4. CTA 写 `/convert/{src}-to-{tgt}`（带 `to`），漏 `to` → 500。
5. `tsc --noEmit` 0 错 + `next build --webpack`（Windows 必带 `--webpack`）。
6. 部署后 `curl` 验标题/canonical/内容（剥离 `<script>` 后断言），排除冷启动。
