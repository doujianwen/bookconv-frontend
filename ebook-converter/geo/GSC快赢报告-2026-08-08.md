## 九、踩过的坑（防复发）

1. **GSC 两种属性（URL 前缀 vs 网域）权限独立**——douhongjian@gmail.com 对 `sc-domain:bookconv.com` 是 `siteUnverifiedUser`，对 `https://www.bookconv.com/` 才是 `siteOwner`。`.env` 必须用 siteOwner 那个。
2. **httplib2 0.32 不读代理环境变量**——本机走 `HTTPS_PROXY=http://127.0.0.1:7897/`，必须用 urllib3.ProxyManager 自定义 transport。
3. **Git Bash 无 `sleep` / `seq` 命令**——监测脚本必须用 Python `time.sleep`。
4. **OAuth「未验证」应用必须加测试用户**——GCP OAuth 同意屏幕 → 发布状态 = 测试 → 加测试用户。
5. **Search Console API 需主动启用**——项目 `326204088231` 默认未启用，需手动启。
6. **28 天窗口看不出低流量新站**——bookconv.com 默认周期太短，用 90 天。
