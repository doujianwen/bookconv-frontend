## 2. 跨类主题提炼（核心洞察）


### 2.1 通用修饰词规律（所有转换类共用）

- **free / online / converter free / online free**：用户强偏好「免费 + 在线」，与 bookconv 免费在线定位高度契合，标题/首屏应前置“Free & Online”。
- **calibre**：大量查询带 `calibre`（epub to azw3 calibre、azw3 to mobi calibre、epub to html calibre、rtf to epub calibre、docx to epub calibre、epub to mobi calibre…）→ Calibre 是用户默认方案，bookconv 应显式对标「Calibre 替代 / 免安装在线版」。
- **github**：epub to azw3 github / epub to txt github / epub to html github → 技术用户找开源/脚本方案，可出「开源替代」内容截流。
- **品牌锚点**：cloudconvert（epub to azw3）、ilovepdf（epub to pdf / djvu to pdf / pdf to epub）→ 大站占据品牌词，bookconv 需在**长尾具体场景**（Linux CLI、扫描件清晰度、NotebookLM 喂料）截流。
- **reddit**：calibre alternative reddit / pdf to epub reddit / docx to epub reddit / epub vs azw3 reddit / best ebook converter reddit → 社区背书意图强，UGC/评测类内容有机会。


### 2.2 设备 / 平台长尾（强意图信号）

- 高频平台词：kindle（paperwhite）、kobo、ipad mini、apple books、chromebook、android、ios、macos、linux。
- 设备故障排查长尾：`can i send azw3 to kindle`、`epub file not opening in apple books / on kindle / on kobo`、`epub file not working on kobo` → 应在对应转换页/格式科普页加「设备兼容 + 故障排查」段。


### 2.3 新兴意图：AI 电子书转有声书（原规划没有！）

- 种子 `ai ebook converter` 实际 autosuggest **强烈偏向音频**：9/10 建议是 `ai ebook to audio converter` / `ai convert ebook to audiobook` 及变体，且带年份后缀 `2025 / 2026`。
- 这是 bookconv 当前**不做**、但内容可截流的高潜意图：写「AI 能把电子书转成有声书吗 / 有哪些工具」指南，截流 `ai ebook to audio converter` 流量。内容需带年份保持时效。


### 2.4 格式对比意图（comparison）

- 明确对比簇：`epub vs azw3`（+for kindle / file size / reddit）、`mobi vs azw3`（+for kindle）、`epub vs pdf`（+for kindle / textbooks / graphic novels / file size）、`pdf vs azw3`。
- 对比类内容需求清晰且带场景，现有 `epub-vs-azw3` / `epub-vs-pdf` 对比页应强化「for kindle / textbooks / graphic novels」等场景段。


### 2.5 Calibre 替代诉求（按平台细分）

- `calibre alternative for android / ios / chromebook / ipad / macos / linux / self hosted` → 用户要**特定平台**的 Calibre 替代，bookconv 可出「Calibre 替代 · [平台]」系列 FAQ/短指南。
