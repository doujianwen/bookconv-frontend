## 六、关键事件仍为空 —— 转化漏斗依旧不可测（最高优先级待办）

报告「平台关键事件数」维度**完全为空**。

时间线回顾：
- 8/10 报告已发现 GA4 关键事件为空 → 根因是全代码库无 `gtag('event')` 调用。
- 8/14 已加 `src/lib/ga.ts`（`trackGAEvent`），在 `ToolPageClient.tsx` / `BatchUpload.tsx` 接入 `file_upload` / `conversion_complete` / `conversion_failed`，提交 ecf9ad5、部署验证通过。
- **但本窗口（含 8/14）关键事件仍为 0** → 说明修复尚未在 GA「关键事件」维度体现，原因二选一：

1. **GA4 后台未把事件标记为「关键事件」**：`gtag('event', ...)` 只是普通事件，不会自动进「关键事件数」维度。必须去 GA4 后台 **Events → 把 `file_upload` / `conversion_complete` 标记为 Key event**，漏斗才测得了。
2. **部署 8/14 晚才生效，当天自然事件极少**：8/14 当天真实用户几乎为 0，事件量不足以显现。

> 🔴 **行动项（必做，否则漏斗永远测不了）**：登录 GA4 后台，把 `file_upload` 与 `conversion_complete` 标记为关键事件。这一步 AI 改不了，必须人工在 GA4 UI 操作。

## 七、给运营 / 课程的动作项

1. **🔴 GA4 后台标记关键事件**（file_upload / conversion_complete）→ 否则「上传→完成」转化漏斗永远为空，之前 ga.ts 修复白做。
2. **区分「自己访问」与「真实用户」**：direct 95% 说明几乎没有真实获客，别用 21 活跃做乐观判断。
3. **0 点击 / 0 自然会话 = 当前唯一杠杆是 CTR（标题/描述）+ 外链**：把排名从均 47.8 往前推，靠外链提域名权威；靠标题改写提点击率。内容已发够（87 页），下一步是「让人点」。
4. **8/14 单日 11 新用户需核实**：疑似部署/调试非自然流量，排查 Vercel 预览、自动化、自身访问，勿计入获客。
5. **中国流量偏多 ≠ 定位有效**：维持海外英文定位，等真实海外点击出现再复盘。
6. **样本太小（21 用户）**：所有数字标「方向性」，不定量决策；等周活稳定 >50 再做细分。

## 八、SEO 课程价值（诚实账本素材）

- **「别被 vanity metric 骗」的活案例**：21 活跃用户看起来像「有流量」，拆来源发现 95% 是站长自己 + 调试工具。GA 与 GSC 双源互证「0 真实获客」。这是 M9 运营增长模块极佳的「数据诚实」教学点。
- **「埋了事件 ≠ 能度量」的坑**：代码层 `gtag('event')` 只是第一步，GA4 后台不标 key event，漏斗维度照样空。AI 建站时这步极易漏，正可写进课程「部署≠完成」章节。
