## 三、数据素养发现（课程可直接引用）⭐

**同一数据源、不同维度，数字不同——这是 GSC 最隐蔽的坑。**

调试中发现：8/9 当天
- `query` 维度求和展示量 = **71**
- `page` 维度求和展示量 = **160**
- `date` 维度（站点真值）= **150**（与 CSV 导出一致）

`query` 维度比真值**少一半**。原因：GSC 在高流量日把低于隐私阈值的词**整批丢弃，且不返回 `(other)` 行**，导致 query 维度的展示量被腰斩（71 vs 150）。

**教训（写进趋势图教学框 ③）**：
- 关键词数 → 用 `query` 维度（只数 GSC 实际列出的词，精确；累计去重 = 增长趋势真值）。
- 展示量/点击 → 必须用 `date` 维度（或 `page` 维度）真值，**绝不能用 query 维度求和**，否则严重低估。
- 这也是「为什么 8/6 前没数据」的延伸：早期词少 + 阈值压制，query 维度连展示都凑不齐。
