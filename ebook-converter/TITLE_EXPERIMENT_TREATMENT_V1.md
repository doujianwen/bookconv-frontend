## Page 1: `/convert/mobi-to-epub`

### Current Title

```
Convert MOBI to EPUB — Free Online Tool
```

**Length**: 36 characters

### Query Intent

核心意图：用户想将 MOBI 格式转换为 EPUB 格式，可能是为了在 Kindle 以外的设备阅读。

### Problem

| 问题 | 说明 |
|---|---|
| 平淡无差异化 | "Free Online Tool" 是通用词，无竞争力 |
| 缺关键 USP | 未强调 "Keep Formatting" 或 "No Sign-up" |
| 位置太差 | pos 70.3，title 需更吸引点击 |

### Proposed Title

```
MOBI to EPUB Converter — Keep Formatting, No Sign-up
```

**Length**: 54 characters

### Change Rationale

- 突出 "Keep Formatting" — 用户核心关切
- 强调 "No Sign-up" — 降低使用门槛
- 去除 "Free Online Tool" — 这是标配，非差异化

### Risk

标题变长可能影响移动端显示，但 54 字符仍在安全范围内（<60）。

### Measurement

- Primary: CTR（当前假设极低，因 pos 70.3）
- Secondary: Position 变化

## Page 2: `/convert/epub-to-txt`

### Current Title

```
Free EPUB to TXT Converter — Extract Clean Text
```

**Length**: 47 characters

### Query Intent

核心意图：用户想从 EPUB 中提取纯文本，可能是为了 AI 处理或简单阅读。

### Problem

| 问题 | 说明 |
|---|---|
| "Clean Text" 模糊 | 未说明为何需要 clean text |
| 缺使用场景 | 未提及 AI/LLM/数据处理等场景 |
| 有曝光但排名差 | pos 62.8，title 吸引力不足 |

### Proposed Title

```
EPUB to TXT — Extract Text for AI, LLM & Reading
```

**Length**: 52 characters

### Change Rationale

- 添加 "AI, LLM" — 匹配当前热门搜索意图
- 添加 "& Reading" — 覆盖更多场景
- 去除 "Free" — 默认免费，不必要

### Risk

可能偏离部分用户的简单阅读意图，但 AI/LLM 是当前主流需求。

### Measurement

- Primary: CTR
- Secondary: Position + Impressions

## Page 3: `/convert/epub-to-azw3`

### Current Title

```
Free EPUB to AZW3 Converter — No Sign-up
```

**Length**: 43 characters

### Query Intent

核心意图：用户想将 EPUB 转换为 AZW3 格式，用于 Kindle 设备阅读。

### Problem

| 问题 | 说明 |
|---|---|
| 缺 Kindle 关键词 | "AZW3" 本身不够明确，用户可能搜 "Kindle" |
| 无场景说明 | 未说明转换目的 |

### Proposed Title

```
EPUB to AZW3 for Kindle — Convert EPUB to Kindle Format
```

**Length**: 57 characters

### Change Rationale

- 添加 "for Kindle" — 匹配用户实际搜索词
- 添加 "Convert EPUB to Kindle Format" — 明确用途
- 保留核心关键词 "EPUB to AZW3"

### Risk

标题较长（57 字符），接近显示上限，但仍在安全范围。

### Measurement

- Primary: CTR
- Secondary: Position + Impressions
