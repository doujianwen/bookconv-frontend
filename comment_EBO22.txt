## Phase 11: 性能优化 — 执行指令

### 任务概述
优化核心 Web Vitals 性能指标，确保 LCP < 2.5s、FID < 100ms、CLS < 0.1。

### 执行步骤

#### Step 1: 性能分析
- 运行 Lighthouse 测试获取基线数据
- 分析 Core Web Vitals 各项指标
- 识别主要性能瓶颈（图片、JS bundle、CSS 等）

#### Step 2: 图片优化
1. 启用 WebP/AVIF 格式转换
2. 添加响应式图片（srcset）
3. 实现懒加载（loading="lazy"）
4. 图片尺寸预分配避免 CLS

#### Step 3: 代码优化
- 组件代码分割（dynamic import）
- Tree-shaking 验证
- Bundle 大小分析和优化
- 第三方库替换优化

#### Step 4: 缓存策略
- Service Worker 缓存配置
- CDN 边缘缓存设置
- 数据库查询缓存
- API 响应缓存
