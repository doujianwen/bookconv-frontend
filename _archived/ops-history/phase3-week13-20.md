# Phase 3: Scaled Backlinks (Week 13-20) — Detailed Execution Steps

## Week 13-14: Data-Driven Backlinks

### Ebook format trend report
- [ ] Collect data:
  - Google Trends: search trends for "epub", "mobi", "azw3", "kindle"
  - SERP data: monthly traffic per keyword
  - User conversion data (from the tool-site backend)
- [ ] Write report: "2026 Ebook Format Usage Report"
- [ ] Report structure:
  1. Executive summary (key findings)
  2. Format market-share analysis
  3. Regional differences (English-speaking vs Asia vs Europe)
  4. Device trends (Kindle vs Kobo vs Apple Books)
  5. Forecast (2027-2028)
- [ ] Publish to: Medium + blog + LinkedIn
- [ ] Proactively send to ebook bloggers/journalists:
  - Email template: "Hi, I compiled a report on ebook format usage trends in 2026. Thought it might be useful for your readers. Full report: [link]. Feel free to use any data in your articles with attribution."
- [ ] Goal: 2-5 high-quality backlinks (DR40-70)
