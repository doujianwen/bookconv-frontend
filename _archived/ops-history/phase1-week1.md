# Phase 1: Cold-Start Backlinks (Week 1-4) — Detailed Execution Steps

## Week 1: Platform Registration & Foundation Building

### Day 1-2: Product Hunt Submission
- [ ] Register a Product Hunt account (log in with Twitter/Google)
- [ ] Create a Product Hunt "Coming Soon" page: https://www.producthunt.com/staging
- [ ] Prepare assets:
  - Logo: 128x128 PNG
  - Cover image: 1160x628 (emphasize "Free, No signup, Unlimited")
  - Demo GIF: 30s showing the conversion flow
  - Tags: #ebook #converter #free #opensource
- [ ] Write the PH description (English):
  - Title: "EbookConverter - Free, Unlimited E-book Format Conversion"
  - Body: "A free online ebook converter that supports 28+ formats including EPUB, MOBI, AZW3, LIT, CBR. No signup required, no file size limits. Built with Calibre engine for maximum compatibility."
- [ ] Pick a launch date (recommended Wed/Thu morning)

### Day 3-4: AlternativeTo Submission
- [ ] Visit https://www.alternative.to/file-converter
- [ ] Search "File Converter" to find the matching page
- [ ] Submit your product: Product name: EbookConverter, URL, Category: File Conversion, Description, Tags: ebook, converter, epub
- [ ] Wait for review (usually 1-3 days)

### Day 5-7: GitHub Repository Setup
- [ ] Create repo: ebook-converter-engine
- [ ] Open-source the core code: Calibre wrapper, format mapping table, error handling
- [ ] README.md should include: project intro + tech stack + tool links + License (MIT)
- [ ] Add GitHub Actions CI + set repository topics
