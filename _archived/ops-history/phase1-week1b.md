## Week 1 (cont.): Reddit Promotion

### r/Calibre promotion strategy
- [ ] Register a Reddit account (stay active; don't post from a brand-new account)
- [ ] Browse r/Calibre for a week to learn the community rules
- [ ] Find relevant threads: search "epub to azw3", "lit to epub", "mobi to epub"
- [ ] Reply template (natural tone, no hard selling):
  "I actually built a free online converter that supports this! It uses Calibre under the hood so it handles all the formats well. No signup needed, just upload and convert. Check it out if you want - [link]. Would love any feedback!"
- [ ] Key: answer the question first, then naturally drop the link
- [ ] Goal: naturally recommend in 3-5 relevant threads per week

### r/kindle promotion strategy
- [ ] Same approach: browse for a week first, learn the community
- [ ] Find Kindle-format-related threads
- [ ] Reply template (lean toward Kindle scenarios):
  "If you need to convert Kindle formats (AZW3, MOBI) to EPUB or vice versa, I built a free tool specifically for ebook formats. It handles the Kindle-specific formats well. No limits, no signup. [link]"

### r/selfpublish promotion strategy
- [ ] Find threads about "ebook formats"
- [ ] Reply angle: from a self-publishing author's perspective
  "For self-publishing, format conversion is essential. I built a free tool that handles all the major ebook formats - EPUB, MOBI, AZW3, PDF. Useful for preparing manuscripts for different platforms. [link]"
